# 0.4 — Install and Configure VS Code

## Download

Download VS Code for Windows from https://code.visualstudio.com/

During installation:

- Add "Open with Code" options if available.
- Add VS Code to the PATH.
- Enable file associations if desired.

## Open a Project

```powershell
cd path\to\project
code .
```

## Recommended Extensions

- ESLint
- Prettier
- Live Server
- GitHub Pull Requests
- Markdown All in One
- Error Lens
- Auto Rename Tag

Only install extensions that you understand and maintain.

## VS Code Settings

Use Settings (`Ctrl+,`) and enable:

- Format on Save
- Auto Save: afterDelay
- Tab Size: 2
- Editor: Word Wrap
- Terminal: Default Profile → PowerShell

## Recommended Frontend Extensions

- ES7+ React/Redux/React-Native snippets
- Thunder Client or Postman for API testing
- GitLens, optionally

## Daily Keyboard Shortcuts

- `Ctrl+P`: quick file open
- `Ctrl+Shift+P`: command palette
- `Ctrl+``: integrated terminal
- `Ctrl+/`: toggle comment
- `Ctrl+B`: toggle sidebar
- `F2`: rename symbol
