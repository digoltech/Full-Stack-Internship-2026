# React Day 17 — UI Libraries and Component Systems

Learn to select and use a React UI library without treating it as a substitute for product design or accessibility work.

## Lessons

- [17.1 — UI Libraries and Ant Design](17.1-UI-Libraries-and-Ant-Design.md): component-library concepts, installation, tables, forms, and practical checks.
- [17.2 — Choosing a Component Library](17.2-Choosing-a-Component-Library.md): compare Ant Design, MUI, Bootstrap, Chakra UI, and other approaches.
- [17.3 — Headless Components, Radix, and shadcn/ui](17.3-Headless-Components-and-shadcn-ui.md): behavior versus styling, source ownership, and accessible dialogs.
- [Day 17 Exercise](Exercise-Day-17.md): build a responsive, searchable team directory.

## Learning Outcomes

By the end of this day, you should be able to explain what a component library provides, select a suitable approach for a project, compose library components with application-owned state, and evaluate basic accessibility and responsive behavior.
