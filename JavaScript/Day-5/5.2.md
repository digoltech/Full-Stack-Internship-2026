# Day 5.2 — JSON and Data Transformation

## Learning Objectives

Understand JSON, convert between JavaScript objects and JSON strings, process API-style data, and transform data into formats suitable for application interfaces.

## 1. What Is JSON?

JSON stands for JavaScript Object Notation. It is a text format used to exchange structured data between applications.

Example JSON:

```json
{
  "id": 1,
  "name": "Asha",
  "active": true,
  "skills": ["JavaScript", "React"]
}
```

JSON resembles JavaScript object syntax, but JSON property names and string values must use double quotes. JSON does not support functions, `undefined`, or comments.

## 2. `JSON.stringify()`

Use `JSON.stringify()` to convert a JavaScript value into a JSON string.

```javascript
const student = {
  name: "Asha",
  marks: 85
};

const jsonString = JSON.stringify(student);

console.log(jsonString);
console.log(typeof jsonString);
```

**Output:**
```text
{"name":"Asha","marks":85}
string
```

You can also format JSON for readability:

```javascript
console.log(JSON.stringify(student, null, 2));
```

## 3. `JSON.parse()`

Use `JSON.parse()` to convert valid JSON text into a JavaScript value.

```javascript
const jsonString = '{"name":"Ravi","marks":75}';

const student = JSON.parse(jsonString);

console.log(student.name);  // Ravi
console.log(student.marks); // 75
```

Invalid JSON causes a parsing error, so handle untrusted or potentially invalid input appropriately.

```javascript
try {
  const data = JSON.parse('{"name":}');
  console.log(data);
} catch (error) {
  console.error("Invalid JSON");
}
```

## 4. Transforming API-Style Data

Applications often receive more data than they need. Transform the response into the fields required by the UI.

```javascript
const users = [
  { id: 1, name: "Asha", email: "asha@example.com", active: true },
  { id: 2, name: "Ravi", email: "ravi@example.com", active: false },
  { id: 3, name: "Neha", email: "neha@example.com", active: true }
];

const activeUsers = users
  .filter(user => user.active)
  .map(user => ({
    id: user.id,
    displayName: user.name,
    email: user.email
  }));

console.log(activeUsers);
```

This example filters inactive users and then creates new objects containing only the required properties.

## 5. Sorting Data

The `sort()` method sorts an array in place, meaning it changes the original array.

```javascript
const prices = [500, 100, 900, 300];

prices.sort((a, b) => a - b);

console.log(prices); // [100, 300, 500, 900]
```

To preserve the original array, sort a copy:

```javascript
const original = [500, 100, 900, 300];

const sorted = [...original].sort((a, b) => a - b);

console.log(sorted);
console.log(original);
```

For numbers, always provide a comparison function when numerical ordering is intended.

## 6. Reducing Data with `reduce()`

`reduce()` combines array elements into a single result, such as a total or frequency map.

```javascript
const prices = [100, 200, 300];

const total = prices.reduce((sum, price) => {
  return sum + price;
}, 0);

console.log(total); // 600
```

Another example: count active users.

```javascript
const users = [
  { name: "Asha", active: true },
  { name: "Ravi", active: false },
  { name: "Neha", active: true }
];

const activeCount = users.reduce((count, user) => {
  return count + (user.active ? 1 : 0);
}, 0);

console.log(activeCount); // 2
```

The initial value `0` is the starting accumulator.
