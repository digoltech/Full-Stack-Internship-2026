# 18.3 — Motion and Icons

**Goal:** Add purposeful interface motion and consistent icons while preserving usability, performance, and accessibility.

## 1. Motion Has a Job

Animation can help users understand a change: a menu opened, a dialog appeared, or an item moved. Motion that does not communicate anything can slow the interface, distract users, or cause discomfort.

Before adding animation, answer:

- What state change should the animation explain?
- Does it delay an important action?
- Does it work when the user requests reduced motion?
- Is the animation short and restrained?

Prefer animating `transform` and `opacity` for common transitions. Animating layout-heavy properties such as `top`, `left`, or large blur regions can require more browser work.

## 2. Install Motion for React

The Motion project is the continuation of Framer Motion. Current examples use the `motion` package and the `motion/react` entry point; older tutorials may install `framer-motion` and import from `framer-motion`. Follow one package's current documentation and do not mix APIs accidentally.

```bash
npm install motion
```

## 3. Animate a Component

```jsx
import { motion, useReducedMotion } from 'motion/react';

export function SavedNotice() {
  const shouldReduceMotion = useReducedMotion();

  return (
    <motion.p
      role="status"
      initial={shouldReduceMotion ? false : { opacity: 0, y: 8 }}
      animate={{ opacity: 1, y: 0 }}
      transition={{ duration: shouldReduceMotion ? 0 : 0.18 }}
    >
      Changes saved.
    </motion.p>
  );
}
```

The message remains understandable without animation. Motion is a visual enhancement, not the only signal that the save succeeded.

## 4. Animate Items Entering and Leaving

Use `AnimatePresence` when a component should animate as it leaves the React tree:

```jsx
import { AnimatePresence, motion } from 'motion/react';

export function FilteredResults({ results }) {
  return (
    <ul>
      <AnimatePresence initial={false}>
        {results.map((result) => (
          <motion.li
            key={result.id}
            initial={{ opacity: 0, y: 6 }}
            animate={{ opacity: 1, y: 0 }}
            exit={{ opacity: 0, y: -6 }}
            transition={{ duration: 0.15 }}
          >
            {result.label}
          </motion.li>
        ))}
      </AnimatePresence>
    </ul>
  );
}
```

Stable keys are necessary for React and the animation library to understand which item entered or left. Avoid animating long lists all at once; it can make the interface feel noisy and increase work.

## 5. Icons with Lucide React

Lucide React provides a consistent set of icon components:

```bash
npm install lucide-react
```

```jsx
import { Search, Trash2 } from 'lucide-react';

export function SearchAndDelete() {
  return (
    <div>
      <label htmlFor="directory-search">Search team members</label>
      <div>
        <Search aria-hidden="true" size={18} />
        <input id="directory-search" type="search" />
      </div>
      <button type="button" aria-label="Delete selected member">
        <Trash2 aria-hidden="true" size={18} />
      </button>
    </div>
  );
}
```

A decorative icon should be hidden from assistive technology with `aria-hidden="true"`. An icon-only button needs an accessible name, usually an `aria-label` or visually hidden text. A text label on a button often makes its meaning clearer than an icon alone.

## 6. Motion and Icon Checklist

- [ ] Motion explains a state change rather than decorating the page.
- [ ] Important feedback is also available as text or semantic state.
- [ ] Reduced-motion preferences are respected for nonessential motion.
- [ ] Lists use stable keys and do not animate excessively.
- [ ] Icon-only controls have clear accessible names.
- [ ] Icons do not replace labels when the action is unfamiliar.
- [ ] Test focus, hover, touch, and keyboard behavior.

## Practice

Add a dismissible success notice with a short entrance animation and reduced-motion handling. Add a delete icon button to a list and make sure its accessible name identifies the item being deleted.
