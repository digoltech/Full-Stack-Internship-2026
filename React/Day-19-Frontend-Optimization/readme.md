# React Day 19 — Frontend Performance and Optimization

Learn to measure real user experience, identify React and asset bottlenecks, make focused changes, and verify improvements without sacrificing accessibility or maintainability.

## Lessons

- [19.1 — Performance Metrics and Baselines](19.1-Performance-Metrics-and-Baselines.md): lab versus field data, current Core Web Vitals, and diagnosis.
- [19.2 — React Rendering and Code Splitting](19.2-React-Rendering-and-Code-Splitting.md): profiling, memoization, deferred updates, transitions, and lazy loading.
- [19.3 — Images, Network, and Asset Delivery](19.3-Images-Network-and-Delivery.md): responsive images, priority, fonts, bundles, caching, and layout stability.
- [19.4 — Performance Testing and Budgets](19.4-Performance-Testing-and-Budgets.md): tool selection, repeatable optimization, field monitoring, and release checks.
- [Day 19 Exercise](Exercise-Day-19.md): audit an app, implement evidence-based changes, and document results.

## Learning Outcomes

By the end of this day, you should be able to measure loading, responsiveness, and stability; use browser and React profiling tools to locate bottlenecks; apply focused optimizations; and communicate the before/after result with its limitations.
