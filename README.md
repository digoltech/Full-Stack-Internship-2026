# Full-Stack MERN Internship 2026

Welcome to the Full-Stack MERN Internship program. This repository contains the complete curriculum, learning materials, and exercises designed to take you from programming fundamentals to building professional-grade full-stack applications.

## 🚀 Curriculum Overview

The program is structured into a logical progression of skills:

### 0. Index & Setup (`/0-index`)
Before diving into code, start here. This section covers:
- Programming fundamentals.
- Environment setup (VS Code, Node.js, Git, GitHub).
- Understanding how the web works (Browsers, DOM, CSSOM).
- Professional profile setup (LinkedIn).

### 1. JavaScript (`/JavaScript`)
Master the language of the web.
- **Day 01 - Day 05**: Core JS concepts, data types, functions, and DOM manipulation.
- **Day 06**: Advanced Asynchronous JS and API integration (including a comprehensive assessment).

### 2. React (`/React`)
Build modern, reactive user interfaces.
- **Day 01 - Day 11**: Components, Hooks, State Management, and Routing.
- **Day 12**: File Uploads and Optimistic UI.
- **Day 13**: Testing and Debugging.
- **Day 14**: Architecture, Tailwind CSS, and Git Workflow.
- **Day 15**: Final React Assessment (MCQs, Debugging, and Coding Tasks).

## 🛠️ Getting Started

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/digoltech/Full-Stack-Internship-2026.git
   ```
2. **Follow the Order**: Start with the `0-index` folder and proceed sequentially through JavaScript and then React.
3. **Complete Exercises**: Each day includes a `readme.md` for summary and an `Exercise-Day-NN.md` for practical application.
