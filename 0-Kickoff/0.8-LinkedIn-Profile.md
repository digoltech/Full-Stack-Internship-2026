# 0.8 — Create a Professional LinkedIn Profile

## Profile Photo

- Use a clear, recent, neutral professional photo.
- Keep the background simple.
- Smile and look toward the camera.

## Headline

Example:

```text
MERN Stack Intern | React | JavaScript | Node.js | MongoDB
```

## About Section

Write 4–6 short paragraphs describing:

- What you are learning
- Your strongest technologies
- Two or three projects
- Your GitHub profile
- Your availability or internship goal

Example structure:

```text
I am learning full-stack web development with the MERN stack.
I build React interfaces and REST APIs using JavaScript and Node.js.
My projects include a task manager and an API-driven catalogue.
View my code on GitHub: <your link>
I am seeking opportunities to learn, contribute, and grow.
```

## Experience

Add internship or project work with:

- Project name
- Technologies
- Problem solved
- Features built
- GitHub or live URL

## Skills

Add:

- JavaScript
- React
- HTML
- CSS
- Node.js
- Express.js
- MongoDB
- Git
- GitHub
- REST APIs

## Featured Section

Add:

- GitHub profile
- Best project repository
- Live project URL
- Internship certificate or final demo

## Professional Habits

- Do not copy another student's About section.
- Keep capitalization and grammar consistent.
- Update the profile after every strong project.
- Post a short completion update with project screenshots and GitHub links.
