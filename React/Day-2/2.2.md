## Section D — Debugging Challenge (10 Marks)

Find and fix all issues in the following component.

```jsx
import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  function increase() {
    count = count + 1;
  }

  return (
    <div>
      <h2>{count}</h2>

      <button onClick={increase()}>
        Increase
      </button>
    </div>
  );
}

export default Counter;
```

Answer the following:

1. Why is directly assigning a new value to `count` incorrect?
2. Why is `onClick={increase()}` incorrect here?
3. Rewrite the component correctly.

### Short Answer — Expected Points

1. State stores changing information, such as a cart count.
2. Props are passed from a parent; state is managed within a component.
3. `onChange` handles changes in an input or similar control.
4. Dependencies determine when an effect needs to re-run.
5. Cleanup prevents timers or listeners from remaining active unnecessarily.

### Debugging Solution

```jsx
import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  function increase() {
    setCount((previous) => previous + 1);
  }

  return (
    <div>
      <h2>{count}</h2>

      <button onClick={increase}>
        Increase
      </button>
    </div>
  );
}

export default Counter;
```

**Explanation:**

- `setCount()` requests a state update.
- `onClick={increase}` passes the function to React.
- The functional updater calculates the new count from the previous value.
