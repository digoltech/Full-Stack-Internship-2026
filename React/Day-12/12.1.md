# Week 4 — Day 12.1: File Uploads and Optimistic Updates

**Topics:** `FormData`, multipart uploads, upload progress, optimistic UI, rollback

## 1. Selecting a File

```jsx
function AvatarForm() {
  function handleSubmit(event) {
    event.preventDefault();
  }

  return (
    <form onSubmit={handleSubmit}>
      <input type="file" accept="image/*" name="avatar" />
      <button type="submit">Upload</button>
    </form>
  );
}
```

Never manually set a file input value. Keep the selected `File` in state or a `FormData` object created during submission.

## 2. Sending `FormData`

```js
const formData = new FormData();
formData.append("title", title);
formData.append("image", selectedFile);

await fetch("/api/uploads", {
  method: "POST",
  body: formData,
});
```

Do not set `Content-Type: multipart/form-data` manually. The browser adds the multipart boundary.

## 3. Upload States

- Validate file type and size before uploading.
- Show a selected-file preview when appropriate.
- Disable duplicate submissions while uploading.
- Show loading, success, and recoverable error states.
- Cancel obsolete uploads where the browser API and server support it.

## 4. Optimistic Updates

Optimistic UI updates the screen immediately, then rolls back if the request fails.

```js
const previous = items;
setItems(nextItems);

try {
  await apiRequest("/items", { method: "POST", body: JSON.stringify(newItem) });
} catch (error) {
  setItems(previous);
  setError(error.message);
}
```

- Snapshot the previous state before changing it.
- Keep mutation logic in a reducer for complex state.
- Prevent duplicate submissions while the request is pending.
- Use optimistic updates only when rollback is understandable and safe.
