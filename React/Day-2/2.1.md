# Week 2 — Day 2.1: Interactive Counter and Student List

**Duration:** 60–90 minutes  
**Level:** Beginner  
**Prerequisite:** React project created using Vite.

## 1. Objective

Build a small interactive React application using:

- `useState`
- Button click events
- Conditional rendering
- List rendering with `map()`

## 2. Step 1 — Create the Component

Create a file named `StudentDashboard.jsx` inside the `src` folder.

```jsx
import { useState } from "react";

function StudentDashboard() {
  const [count, setCount] = useState(0);
  const [showStudents, setShowStudents] = useState(true);

  const students = [
    "Aarav",
    "Priya",
    "Neel",
    "Krisha",
    "Dev"
  ];

  return (
    <div>
      <h1>Student Dashboard</h1>

      <h2>Counter: {count}</h2>

      <button onClick={() => setCount(count + 1)}>
        Increase
      </button>

      <button onClick={() => setCount(count - 1)}>
        Decrease
      </button>

      <button onClick={() => setCount(0)}>
        Reset
      </button>

      <hr />

      <button onClick={() => setShowStudents(!showStudents)}>
        {showStudents ? "Hide Students" : "Show Students"}
      </button>

      {showStudents ? (
        <ul>
          {students.map((student) => (
            <li key={student}>{student}</li>
          ))}
        </ul>
      ) : (
        <p>Student list is hidden.</p>
      )}
    </div>
  );
}

export default StudentDashboard;
```

## 3. Step 2 — Use the Component

Open `App.jsx` and replace its content with:

```jsx
import StudentDashboard from "./StudentDashboard";

function App() {
  return <StudentDashboard />;
}

export default App;
```

Run the project:

```bash
npm run dev
```

Open the local URL shown in the terminal.
