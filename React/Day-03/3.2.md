## Section E — Debugging Exercise

Identify and correct the issues in this component.

```jsx
function StudentList() {
  const students = [
    { id: 1, name: "Aarav" },
    { id: 2, name: "Priya" }
  ];

  return (
    <div>
      {students.length && (
        students.map((student) => (
          <p>{student.name}</p>
        ))
      )}
    </div>
  );
}
```

Students should identify:

1. Why the empty-list condition is unsafe.
2. Why list keys are missing.
3. How to display a proper message when the list is empty.

### One Possible Correction

```jsx
function StudentList() {
  const students = [
    { id: 1, name: "Aarav" },
    { id: 2, name: "Priya" }
  ];

  return (
    <div>
      {students.length > 0 ? (
        students.map((student) => (
          <p key={student.id}>{student.name}</p>
        ))
      ) : (
        <p>No students found.</p>
      )}
    </div>
  );
}
```
