## 2. Introduction to Conditional Rendering

Conditional rendering means displaying different UI elements depending on a condition.

For example:

- Display a welcome message when a user logs in.
- Show an error when a form is invalid.
- Display "No tasks found" when a task list is empty.
- Show a loading indicator while fetching data.
- Display a different button depending on whether a task is completed.

React uses normal JavaScript conditions to determine what should appear on the screen.

## 3. Using `if` Statements

Use an `if` statement when you want to decide what a component should return.

### Example: Login Status

```jsx
function LoginMessage({ isLoggedIn }) {
  if (isLoggedIn) {
    return <h2>Welcome back!</h2>;
  }

  return <h2>Please log in.</h2>;
}

export default LoginMessage;
```

### How it works

- If `isLoggedIn` is `true`, React renders the welcome message.
- Otherwise, it renders the login message.
- The condition is evaluated whenever the component renders.

### Practice

Create a component named `AgeMessage` that accepts an `age` prop.

- If the age is 18 or above, display "Eligible to vote".
- Otherwise, display "Not eligible to vote".

## 4. Using the Ternary Operator

The ternary operator is useful when you want to display one of two alternatives directly inside JSX.

### Syntax

```jsx
condition ? expressionIfTrue : expressionIfFalse
```

### Example: Login Button

```jsx
function LoginButton({ isLoggedIn }) {
  return (
    <button>
      {isLoggedIn ? "Logout" : "Login"}
    </button>
  );
}

export default LoginButton;
```

### Example: Change a Message

```jsx
function Status({ isAvailable }) {
  return (
    <p>
      {isAvailable ? "Available" : "Unavailable"}
    </p>
  );
}

export default Status;
```

**Important:** A ternary expression is best for choosing between two alternatives. Avoid deeply nested ternaries because they make code difficult to read.

## 5. Using Logical AND (`&&`)

Use `&&` when you want to render something only if a condition is true.

### Example: Show a Notification

```jsx
function Notification({ hasNotification }) {
  return (
    <div>
      <h2>Dashboard</h2>

      {hasNotification && (
        <p>You have a new notification!</p>
      )}
    </div>
  );
}

export default Notification;
```

If `hasNotification` is true, the notification appears. If it is false, the paragraph is not rendered.

### Important JavaScript Detail

Be careful when using numbers with `&&`.

```jsx
{tasks.length && <p>Tasks available</p>}
```

When `tasks.length` is `0`, React can display `0` instead of rendering nothing.

A safer version is:

```jsx
{tasks.length > 0 && <p>Tasks available</p>}
```

## 6. Conditional Rendering with State

In real applications, conditions often depend on state that changes after user interaction.

### Example: Show and Hide a Message

```jsx
import { useState } from "react";

function ToggleMessage() {
  const [showMessage, setShowMessage] = useState(false);

  return (
    <div>
      <button
        onClick={() => setShowMessage((previous) => !previous)}
      >
        {showMessage ? "Hide Message" : "Show Message"}
      </button>

      {showMessage && <p>Welcome to React!</p>}
    </div>
  );
}

export default ToggleMessage;
```

### What students should understand

1. `useState(false)` initially hides the message.
2. Clicking the button changes the state.
3. React renders the updated UI.
4. The button label and message depend on the current state.

## 7. Introduction to List Rendering

List rendering means displaying multiple elements from an array.

For example, a student dashboard may contain many student names. Instead of writing an individual JSX element for every student, we can use `map()`.

### Example: Simple Array

```jsx
function StudentList() {
  const students = ["Aarav", "Priya", "Neel", "Krisha"];

  return (
    <ul>
      {students.map((student) => (
        <li key={student}>{student}</li>
      ))}
    </ul>
  );
}

export default StudentList;
```

### How `map()` works

- It processes each item in an array.
- It returns a new array containing the result of the callback.
- React renders the returned JSX elements.

For the array:

```js
["Aarav", "Priya", "Neel"]
```

React renders three list items.

### Why not write every item manually?

Without `map()`, adding or removing items requires manually changing the JSX. Using `map()` makes the UI easier to maintain when the data changes.

## 8. Rendering Arrays of Objects

In real applications, data usually contains multiple properties rather than just a name.

### Example: Student Records

```jsx
function StudentList() {
  const students = [
    { id: 101, name: "Aarav", course: "MERN" },
    { id: 102, name: "Priya", course: "React" },
    { id: 103, name: "Neel", course: "Node.js" }
  ];

  return (
    <div>
      <h2>Students</h2>

      {students.map((student) => (
        <div key={student.id}>
          <h3>{student.name}</h3>
          <p>Course: {student.course}</p>
        </div>
      ))}
    </div>
  );
}

export default StudentList;
```

Each student is an object. We use `student.name`, `student.course`, and `student.id` to access its properties.

## 9. Understanding React Keys

A `key` helps React identify which list item corresponds to which data item when a list changes.

Example:

```jsx
{students.map((student) => (
  <p key={student.id}>{student.name}</p>
))}
```

### Key rules

- Use a stable, unique identifier, such as a database ID.
- Avoid using array indexes as keys when items can be inserted, removed, or reordered.
- Do not generate a new random key during every render.
- Keys should be unique among siblings in the rendered list.

A key is for React's reconciliation process. It is not automatically passed to the child component as a normal prop.

## 10. Combining State and List Rendering

Now let's display a list that changes when a user clicks a button.

```jsx
import { useState } from "react";

function StudentList() {
  const [students, setStudents] = useState([
    { id: 1, name: "Aarav" },
    { id: 2, name: "Priya" }
  ]);

  function addStudent() {
    const newStudent = {
      id: Date.now(),
      name: "New Student"
    };

    setStudents((previous) => [...previous, newStudent]);
  }

  return (
    <div>
      <h2>Students: {students.length}</h2>

      <button onClick={addStudent}>Add Student</button>

      {students.length === 0 ? (
        <p>No students available.</p>
      ) : (
        <ul>
          {students.map((student) => (
            <li key={student.id}>{student.name}</li>
          ))}
        </ul>
      )}
    </div>
  );
}

export default StudentList;
```

This example combines three important ideas:

- `useState` stores the list.
- The event handler adds a student.
- `map()` renders the updated list.

The ternary operator displays a message if the list is empty.

## 11. Filtering Lists

Filtering allows us to display only the items that match a condition.

### Example: Display Completed Tasks

```jsx
const tasks = [
  { id: 1, title: "Learn JSX", completed: true },
  { id: 2, title: "Learn React State", completed: false },
  { id: 3, title: "Practise Components", completed: true }
];

const completedTasks = tasks.filter((task) => task.completed);
```

Render the filtered list:

```jsx
<ul>
  {completedTasks.map((task) => (
    <li key={task.id}>{task.title}</li>
  ))}
</ul>
```

### Important distinction

- `map()` transforms each array item into something else, such as JSX.
- `filter()` creates an array containing only the items that pass a condition.

They can also be combined:

```jsx
{tasks
  .filter((task) => !task.completed)
  .map((task) => (
    <li key={task.id}>{task.title}</li>
  ))}
```

This renders only the pending tasks.

## 12. Complete Example: Task List

The following example combines conditional rendering, list rendering, and state.

```jsx
import { useState } from "react";

function TaskList() {
  const [tasks, setTasks] = useState([
    { id: 1, title: "Learn JSX", completed: false },
    { id: 2, title: "Practise useState", completed: true }
  ]);

  function toggleTask(id) {
    setTasks((previousTasks) =>
      previousTasks.map((task) =>
        task.id === id
          ? { ...task, completed: !task.completed }
          : task
      )
    );
  }

  return (
    <div>
      <h2>My Tasks</h2>

      {tasks.length === 0 ? (
        <p>No tasks available.</p>
      ) : (
        <ul>
          {tasks.map((task) => (
            <li key={task.id}>
              <span
                style={{
                  textDecoration: task.completed
                    ? "line-through"
                    : "none"
                }}
              >
                {task.title}
              </span>

              <button onClick={() => toggleTask(task.id)}>
                {task.completed ? "Undo" : "Complete"}
              </button>
            </li>
          ))}
        </ul>
      )}
    </div>
  );
}

export default TaskList;
```

### Expected behaviour

- Two tasks appear initially.
- Completed tasks have a line through their text.
- Clicking Complete marks a task as completed.
- Clicking Undo marks it as pending.
- If the array is empty, a message appears instead of the list.

## 13. Common Mistakes

### Mistake 1: Forgetting the key

Incorrect:

```jsx
students.map((student) => <li>{student.name}</li>)
```

Correct:

```jsx
students.map((student) => (
  <li key={student.id}>{student.name}</li>
))
```

### Mistake 2: Using `if` directly inside JSX

You cannot place a normal `if` statement directly inside JSX braces.

Incorrect:

```jsx
return (
  <div>
    {if (isLoggedIn) { "Welcome" }}
  </div>
);
```

Use a ternary, logical AND, or determine the value before the `return`.

### Mistake 3: Modifying arrays directly

Incorrect:

```jsx
tasks.push(newTask);
```

Correct:

```jsx
setTasks((previous) => [...previous, newTask]);
```

### Mistake 4: Using array indexes as keys everywhere

An index key may work for a static list, but it can cause incorrect UI reuse when items are inserted, deleted, or reordered. Prefer stable IDs.

### Mistake 5: Using `&&` with a number

Incorrect:

```jsx
{tasks.length && <TaskList />}
```

Correct:

```jsx
{tasks.length > 0 && <TaskList />}
```
