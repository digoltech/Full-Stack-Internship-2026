# 0.2 — JavaScript, React, Node.js, and the MERN Stack

## HTML

HTML describes page structure.

```html
<button>Save</button>
```

## CSS

CSS controls presentation.

```css
button {
  background: blue;
  color: white;
}
```

## JavaScript

JavaScript adds behavior and calculations.

```javascript
button.addEventListener("click", () => {
  console.log("Saved");
});
```

JavaScript can run in a browser or on a server.

## React

React is a JavaScript library for building reusable user interfaces.

```jsx
function Welcome({ name }) {
  return <h1>Welcome, {name}</h1>;
}
```

React helps manage components, state, events, routing, and API-driven screens.

## Node.js

Node.js runs JavaScript outside the browser. It provides:

- Server-side application code
- npm packages
- File system access
- Network APIs
- Command-line tools

## Express.js

Express is a Node.js framework for building web servers and REST APIs.

## MongoDB

MongoDB stores application data as JSON-like documents.

## MERN Stack

```text
React       = user interface
Node.js     = server runtime
Express.js  = server framework and API routes
MongoDB     = database
```

## Browser and Server

```text
Browser → HTTP Request → Express API → MongoDB
   ↑                                      |
   └──────── HTTP Response ───────────────┘
```
