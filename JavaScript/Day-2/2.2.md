# Day 2.2 — Callbacks and Higher-Order Functions

## Learning Objectives

Understand callbacks, passing functions as arguments, returning functions, and building reusable operations.

## 1. What Is a Callback?

A callback is a function passed to another function so that it can be called by that function.

```javascript
function greet(name, callback) {
  console.log(`Hello, ${name}`);
  callback();
}

function showMessage() {
  console.log("Welcome to the internship!");
}

greet("Aarav", showMessage);
```

**Output:**
```text
Hello, Aarav
Welcome to the internship!
```

Notice that we pass `showMessage`, not `showMessage()`. Passing the function allows `greet()` to decide when to call it.

## 2. Callbacks with Arrow Functions

Callbacks can also be written inline using arrow functions.

```javascript
function calculate(a, b, operation) {
  return operation(a, b);
}

const result = calculate(10, 5, (x, y) => x + y);

console.log(result); // 15
```

The `operation` parameter receives a function. This makes `calculate()` reusable with different operations.

```javascript
console.log(calculate(10, 5, (x, y) => x - y)); // 5
console.log(calculate(10, 5, (x, y) => x * y)); // 50
```

## 3. What Is a Higher-Order Function?

A higher-order function is a function that takes another function as an argument or returns another function.

Example:

```
function greet(name) {
  return "Hello " + name;
}

function display(callback) {
  console.log(callback("Rahil"));
}

display(greet); // Hello Rahil
```

How it works:

1. `greet()` returns a greeting message.
2. `display()` accepts a function as an argument.
3. `display()` calls that function and prints the result.

Real-life example: Imagine a food delivery app where you give a delivery person an address. The delivery person performs a task using the information you provided. Similarly, a higher-order function accepts another function to perform a specific task.

Practice task: Create a function `calculate()` that accepts two numbers and another function to perform addition or multiplication.

## 4. Synchronous Callbacks

A synchronous callback runs during the current function execution.

```javascript
function processTask(callback) {
  console.log("Task started");
  callback();
  console.log("Task completed");
}

processTask(() => {
  console.log("Processing data");
});
```

**Output:**
```text
Task started
Processing data
Task completed
```

The callback executes immediately before the final message.

## 5. Asynchronous Callbacks

Some callbacks execute later, after an asynchronous operation completes.

```javascript
console.log("First");

setTimeout(() => {
  console.log("Second");
}, 1000);

console.log("Third");
```

**Output order:**
```text
First
Third
Second
```

`setTimeout()` schedules the callback to run later. JavaScript continues executing the remaining synchronous code first.

## 6. Callback-Based Data Processing

Callbacks are useful when processing data with custom rules.

```javascript
function processMarks(marks, callback) {
  return marks.map(callback);
}

const marks = [50, 60, 70];

const updatedMarks = processMarks(
  marks,
  mark => mark + 5
);

console.log(updatedMarks); // [55, 65, 75]
```

The processing function can be reused with different callback logic.
