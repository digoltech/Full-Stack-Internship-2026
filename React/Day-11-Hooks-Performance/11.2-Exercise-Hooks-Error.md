function useCounter(start) {

### Section B — Expected Points

1. React tracks hook state by call order (an internal list). If the order changes (for example, due to a condition), the state is assigned to the wrong hook, causing bugs.
2. Logic. To share data, use lifting state or Context (for example, `CartContext`).
3. Objects, arrays and functions are compared by reference. A new object `{ id: 1 }` created every render is not equal to the previous one, so `memo` sees changed props and re-renders anyway. Fix by creating it once (`useMemo`, `useCallback`, or outside the component).
4. Justified: heavy calculation on a large list, or stabilising a value used by a memoised child/effect. Not justified: a trivial calculation like `a + b`.
5. React's error-catching lifecycle methods (`getDerivedStateFromError`, `componentDidCatch`) exist only for classes. Place it around `<Outlet />` in the main layout (and around risky widgets), so navigation remains available.

### Section C

1. `1`. The initial render only; `Child` has no props and is memoised.
2. `4`. The inline function is new on each render, so `memo` re-renders the child on every click (1 initial + 3 clicks).
3. `false`
4. The boundary's fallback "Something went wrong". The `h1` is also not displayed, because the whole boundary subtree is replaced.
5. It still shows the old value. Each hook call has independent state. Only after a re-mount or reload would it read `5` from `localStorage`. (Share state with Context if both must stay in sync.)

Sample for Exercise 1:

```jsx
export function usePrevious(value) {
  const ref = useRef();
  useEffect(() => {
    ref.current = value;
  }, [value]);
  return ref.current;       // runs BEFORE the effect, so it is the previous value
}

export function useWindowWidth() {
  const [width, setWidth] = useState(window.innerWidth);
  useEffect(() => {
    const onResize = () => setWidth(window.innerWidth);
    window.addEventListener("resize", onResize);
    return () => window.removeEventListener("resize", onResize);
  }, []);
  return width;
}
```

### Section E — Problems and Fix

Problems:

1. `useCounter` calls `useState` after a conditional return (violates the Rules of Hooks).
2. Returns different shapes (`0` vs object).
3. `increment` uses `count + 1` instead of `setCount((c) => c + 1)` (stale closure risk).
4. `useData(options)`: `options` is a new object each render, so the effect runs after every render (infinite loop with `setData`).
5. No `response.ok` check, no error/loading state, no cleanup or abort.
6. `data` is `undefined` at first, so `data.products.length` crashes.
7. `useMemo` has no dependency array and is not worth using here.
8. `memo` is not imported.
9. `user={{ name: "Asha" }}` creates a new object every render, so `memo` is useless. Define it outside the component or with `useMemo`.
10. Missing `key`/display name for the memoised arrow component (optional note).

Corrected version:

```jsx
import { memo, useEffect, useState } from "react";

function useCounter(start = 0) {
  const [count, setCount] = useState(start < 0 ? 0 : start);
  return { count, increment: () => setCount((c) => c + 1) };
}

function useData(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState("");

  useEffect(() => {
    const controller = new AbortController();

    async function load() {
      try {
        setLoading(true);
        setError("");
        const res = await fetch(url, { signal: controller.signal });
        if (!res.ok) throw new Error(`Status ${res.status}`);
        setData(await res.json());
      } catch (err) {
        if (err.name !== "AbortError") setError(err.message);
      } finally {
        if (!controller.signal.aborted) setLoading(false);
      }
    }

    load();
    return () => controller.abort();
  }, [url]);

  return { data, loading, error };
}

function Page() {
  const { data, loading, error } = useData("https://dummyjson.com/products");

  if (loading) return <p>Loading...</p>;
  if (error) return <p role="alert">{error}</p>;

  const total = data.products.length * 2;     // cheap calculation: no useMemo needed
  return <p>{total}</p>;
}

const Greeting = memo(function Greeting({ user }) {
  return <h1>{user.name}</h1>;
});

const user = { name: "Asha" };   // stable reference

function App() {
  return <Greeting user={user} />;
}
```
