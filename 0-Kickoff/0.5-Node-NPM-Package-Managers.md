# 0.5 — Node.js, npm, and Package Managers

## Node.js

Node.js is a JavaScript runtime outside the browser.

Check installation:

```powershell
node --version
npm --version
```

Install a current LTS Node.js version from https://nodejs.org/

Node.js does not replace the browser. It runs JavaScript on the server, command line, build tools, and development tools.

## npm

npm is installed with Node.js.

```powershell
npm init -y
npm install package-name
npm install -D package-name
npm run dev
```

Important files:

- `package.json`: project scripts and direct dependencies
- `package-lock.json`: exact dependency resolution
- `node_modules`: installed packages; usually excluded from Git

## npx

`npx` runs npm package executables.

```powershell
npx vite --version
```

## yarn

yarn is an alternative package manager.

```powershell
corepack enable
corepack yarn --version
corepack yarn add react
```

## pnpm

pnpm uses linked package storage and strict dependency behavior.

```powershell
corepack enable
corepack pnpm --version
corepack pnpm add react
```

## Bun

Bun is a JavaScript runtime and package tool with an npm-compatible package workflow.

```powershell
bun --version
bun add react
bun run dev
```

On Windows, install Bun using its official Windows instructions from https://bun.sh/

## Which One Should a Student Use?

For this curriculum, use:

- **Node.js + npm** for the main setup
- One package manager per project
- Do not mix npm and yarn lockfiles in the same project

The lockfile is useful because it makes installs reproducible.
