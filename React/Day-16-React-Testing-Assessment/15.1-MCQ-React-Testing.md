# 15.1 — React Testing MCQs

**Topics:** Components, hooks, routing, Context, testing, API states

**Total Marks:** 20  
**Suggested Duration:** 20 minutes

*Choose one answer for each question. Each question carries 2 marks.*

1. Which hook provides and manages a component's changing values?
   - A. `useFetch`
   - B. `useState`
   - C. `useRoute`
   - D. `useEffectOnly`

2. Which hook runs side effects after React commits a render?
   - A. `useMemo`
   - B. `useEffect`
   - C. `useRef`
   - D. `useReducer`

3. Which query should be preferred for a button in a React test?
   - A. `document.querySelector("button")`
   - B. `getByRole("button", { name: "Save" })`
   - C. `getByClassName("save")`
   - D. `getByTag("BUTTON")`

4. What is the main purpose of `Testing Library`?
   - A. Test implementation details
   - B. Test behavior from the user's perspective
   - C. Replace React Router
   - D. Compile JSX

5. Which library commonly provides a browser-like environment for Vitest component tests?
   - A. jsdom
   - B. Express
   - C. MongoDB
   - D. Redux

6. Why should state updates create new arrays or objects?
   - A. It is required for HTML.
   - B. It prevents direct mutation and allows React to detect changes.
   - C. It converts state to JSON.
   - D. It disables re-rendering.

7. Which Context pattern lets every provider consumer call a safe, named hook?
   - A. Context plus a custom consumer hook
   - B. Direct global variables
   - C. `document.cookie`
   - D. `window.state`

8. What does `React.lazy()` do?
   - A. Stops all application rendering
   - B. Loads a component or page asynchronously
   - C. Delays all JavaScript forever
   - D. Converts props to state

9. Which UI state should appear before API data finishes loading?
   - A. Loading
   - B. 404 page
   - C. Deleted state
   - D. Browser storage state

10. What is the purpose of a route-level Error Boundary?
    - A. Catch every JavaScript error anywhere in the operating system
    - B. Prevent one render crash from blanking the whole layout
    - C. Replace `try/catch`
    - D. Validate form fields

11. Which JSX pattern renders a list of components from an array?
    - A. `items.loop()`
    - B. `items.map(item => <Item key={item.id} item={item} />)`
    - C. `for (item of items)`
    - D. `items.render()`

12. Why should props be treated as read-only?
    - A. They must always be strings
    - B. A component should not directly change data owned by its parent
    - C. Props cannot contain objects
    - D. React deletes them after render

13. Which controlled input pattern is correct?
    - A. `value={name} onChange={event => setName(event.target.value)}`
    - B. `defaultValue={setName()}`
    - C. `value={undefined}`
    - D. `onChange={name}`

14. Which hook is most appropriate for state with many related update actions?
    - A. `useReducer`
    - B. `useFetch`
    - C. `useParams`
    - D. `useOutlet`

15. What is the purpose of `useMemo`?
    - A. Always replace `useState`
    - B. Remember a calculated value until dependencies change
    - C. Fetch API data
    - D. Create DOM elements

16. Which React Router component provides nested route content?
    - A. `Outlet`
    - B. `Navigate`
    - C. `RouteError`
    - D. `Browser`

17. Which hook reads dynamic path values?
    - A. `useState`
    - B. `useParams`
    - C. `useRef`
    - D. `useCallback`

18. Which response should a user-facing React app handle as loading, error, empty, or success?
    - A. Every API request
    - B. Only `GET` requests
    - C. Only local state
    - D. Only route changes

19. Why are unique stable keys preferred for list rendering?
    - A. They improve React's ability to match items across renders
    - B. They make arrays immutable
    - C. They prevent CSS loading
    - D. They replace component state

20. Which practice helps prevent stale search responses?
    - A. `AbortController` or ignoring responses for an outdated query
    - B. Calling `fetch()` in the render body
    - C. Using array `index` keys
    - D. Disabling `useEffect`
