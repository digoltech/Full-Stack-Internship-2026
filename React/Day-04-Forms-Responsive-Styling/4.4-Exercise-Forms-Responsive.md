# Exercise Day 4 — Controlled Forms and Validation

Build a registration form using controlled React inputs.

## Requirements

1. Create name, email, password, and course fields.
2. Store form values in one state object or clearly named state variables.
3. Handle every input with `onChange` and `value`.
4. Prevent page reload on form submission.
5. Require a name with at least two characters.
6. Validate the email format.
7. Require a password with at least eight characters.
8. Require one course to be selected.
9. Display field-specific validation messages after submission or blur.
10. Show a success summary and clear the form after a valid submission.

## Submission

- Create or update a Vite React project.
- Add a reusable submit button or field component.
- Test valid submission and each invalid field.
- Ensure labels, error text, and focus states are accessible.

## Optional Responsive Styling

- Convert the form to a mobile-first layout.
- Use a single-column layout below 700px and two columns above 700px.
- Reuse CSS variables for spacing and form control colors.
