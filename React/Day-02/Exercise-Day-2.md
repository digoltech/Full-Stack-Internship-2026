# Exercise Day 2 — React State and Effects

Build a small interactive React application using `useState` and `useEffect`.

## Requirements

1. Create a counter with increment, decrement, reset, and step controls.
2. Do not allow the counter to fall below zero.
3. Add an input whose value is controlled by React state.
4. Display the character count for the input value.
5. Add a feature that can be switched on and off with a state variable.
6. Use `useEffect` to update `document.title` when the counter changes.
7. Use a second effect that sets an interval and cleans it up correctly.
8. Add at least one array state example, such as a visible activity list.
9. Add three buttons that update state based on the previous state.
10. Avoid direct state mutation and log the state only when useful for debugging.

## Submission

- Create or update a Vite React project.
- Put the main exercise in a separate component file.
- Run the app and test all controls.
- Include a short explanation of one effect and one cleanup.
