# React Day 20 — Project Ideas

Choose a practical project, build it to a professional standard, and publish the result. Read the guide before selecting an idea.

## Start Here

- [20.0 — Project Guide and Standards](20.0-Project-Guide-and-Standards.md): tech stack, quality checklist, folder structure, Git and commit conventions, README, testing, deployment, references, and presentation tips.

## Project Ideas

- [20.1 — Easy Projects](20.1-Easy-Projects.md): 7 beginner projects for practising React fundamentals and shipping a first complete app.
- [20.2 — Medium Projects](20.2-Medium-Projects.md): 7 multi-screen projects with deeper data flows, forms, routing, and testing.
- [20.3 — Hard Projects](20.3-Hard-Projects.md): 7 advanced product ideas requiring careful scope, backend rules, and release-quality thinking.

## Suggested Order

1. Read 20.0 and set up your GitHub repository.
2. Finish one Easy project, including deployment and documentation.
3. Finish one Medium project.
4. Choose one Hard project only when you can give it enough time; deliver it in milestones.

Each idea includes a definition, a plain-language explanation of what to build, practical use cases, suggested features and stack, and links to APIs, UI inspiration, or technical references. Treat stretch goals as optional; finish the core user journey first.
