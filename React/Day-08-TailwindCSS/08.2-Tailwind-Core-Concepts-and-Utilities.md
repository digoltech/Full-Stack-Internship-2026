# 08.2 — Tailwind Core Concepts and Utilities

**Goal:** Master the most common utility categories and learn how to handle hover, focus, and active states.

## 1. The Layout System (Flexbox & Grid)

Tailwind makes complex layouts simple by providing utilities for Flexbox and CSS Grid.

### Flexbox
Use `flex` to enable flexbox, then control alignment and direction.
```jsx
<div className="flex items-center justify-between p-4 bg-gray-100">
  <div>Logo</div>
  <div className="flex gap-4">
    <a href="#">Home</a>
    <a href="#">About</a>
    <a href="#">Contact</a>
  </div>
</div>
```
- `flex`: `display: flex;`
- `items-center`: `align-items: center;` (Vertical alignment)
- `justify-between`: `justify-content: space-between;` (Horizontal spacing)
- `gap-4`: `gap: 1rem;` (Spacing between children)

### CSS Grid
Use `grid` for 2D layouts.
```jsx
<div className="grid grid-cols-1 md:grid-cols-3 gap-6 p-6">
  <div className="bg-blue-100 p-4 rounded">Item 1</div>
  <div className="bg-blue-100 p-4 rounded">Item 2</div>
  <div className="bg-blue-100 p-4 rounded">Item 3</div>
</div>
```
- `grid`: `display: grid;`
- `grid-cols-3`: `grid-template-columns: repeat(3, minmax(0, 1fr));`
- `gap-6`: Spacing between grid cells.

## 2. Spacing, Sizing, and Typography

### Spacing (Padding & Margin)
Tailwind uses a numeric scale where `1` = `0.25rem` (4px).
- `p-4`: Padding all sides (1rem/16px).
- `px-2`: Padding left and right.
- `py-8`: Padding top and bottom.
- `m-auto`: Margin auto.
- `mt-10`: Margin top.

### Sizing
- `w-full`: `width: 100%;`
- `w-1/2`: `width: 50%;`
- `h-screen`: `height: 100vh;`
- `max-w-7xl`: Sets a maximum width for containers.

### Typography
- `text-sm`, `text-base`, `text-xl`, `text-4xl`: Font sizes.
- `font-light`, `font-medium`, `font-bold`: Font weights.
- `text-center`, `text-right`: Text alignment.
- `leading-tight`, `leading-loose`: Line height.
- `tracking-wide`: Letter spacing.

## 3. Colors and Backgrounds

Tailwind provides a huge palette of colors (Slate, Gray, Zinc, Neutral, Stone, Red, Orange, Amber, Yellow, Lime, Green, Emerald, Teal, Cyan, Sky, Blue, Indigo, Violet, Purple, Fuchsia, Pink, Rose).

- `text-blue-600`: Blue text.
- `bg-slate-800`: Dark slate background.
- `border-red-500`: Red border.
- `bg-opacity-50`: Sets background transparency.

## 4. Interactive States (Hover, Focus, Active)

You can apply styles based on the state of an element by prefixing the utility with the state name.

### Hover
`hover:bg-blue-700` — Changes background color when the mouse is over the element.

### Focus
`focus:ring-2 focus:ring-blue-500` — Adds a ring around the element when it is focused (essential for accessibility).

### Active
`active:scale-95` — Shrinks the element slightly when clicked.

### Example: A Professional Button
```jsx
<button className="bg-blue-500 text-white px-6 py-2 rounded-lg font-medium 
                   transition-all duration-200 
                   hover:bg-blue-600 hover:shadow-lg 
                   active:scale-95 
                   focus:outline-none focus:ring-2 focus:ring-blue-400 focus:ring-offset-2">
  Get Started
</button>
```

## 5. Customizing the Theme

If the default colors or spacing aren't enough, you can extend them in `tailwind.config.js`.

```javascript
export default {
  content: ["./index.html", "./src/**/*.{js,ts,jsx,tsx}"],
  theme: {
    extend: {
      colors: {
        brand: {
          light: '#3fbaeb',
          DEFAULT: '#0fa9e6',
          dark: '#0c87b8',
        },
      },
      spacing: {
        '128': '32rem',
      }
    },
  },
  plugins: [],
}
```
Now you can use `bg-brand` or `text-brand-dark` and `p-128` in your HTML.
