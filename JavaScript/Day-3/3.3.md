# Day 3.3 — Immutability and Object Operations

## Learning Objectives

Understand references, shallow copying, immutability, and common object operations used in React and full-stack applications.

## 1. Understanding Object References

Objects are reference types. Assigning an object to another variable does not automatically create a separate copy.

```javascript
const user1 = {
  name: "Ravi",
  age: 22
};

const user2 = user1;

user2.age = 25;

console.log(user1.age); // 25
```

Both variables refer to the same object. Therefore, changing the object through either variable affects the same data.

## 2. What Is Immutability?

Immutability means avoiding direct modification of existing data. Instead, create a new object or array containing the desired changes.

```javascript
const user = {
  name: "Ravi",
  age: 22
};

const updatedUser = {
  ...user,
  age: 25
};

console.log(user.age);        // 22
console.log(updatedUser.age); // 25
```

Immutability is especially important in React state updates because React relies on state changes to determine when components should update.

## 3. Updating Nested Objects

Spread syntax only copies one level at a time. To update a nested property without modifying the original object, copy each affected level.

```javascript
const student = {
  name: "Asha",
  address: {
    city: "Anand",
    state: "Gujarat"
  }
};

const updatedStudent = {
  ...student,
  address: {
    ...student.address,
    city: "Vadodara"
  }
};

console.log(student.address.city);        // Anand
console.log(updatedStudent.address.city); // Vadodara
```

The nested `address` object must also be copied. Otherwise, the original and updated objects would share that nested reference.

## 4. Useful Object Methods

### `Object.keys()`

Returns an array of an object's own enumerable property names.

```javascript
const product = {
  name: "Mouse",
  price: 500,
  stock: 20
};

console.log(Object.keys(product));
// ["name", "price", "stock"]
```

### `Object.values()`

Returns an array of property values.

```javascript
console.log(Object.values(product));
// ["Mouse", 500, 20]
```

### `Object.entries()`

Returns an array of key-value pairs.

```javascript
console.log(Object.entries(product));
```

This is useful when iterating over an object's properties.

### `Object.assign()`

Copies enumerable properties from source objects into a target object.

```javascript
const defaults = { theme: "light", language: "en" };
const preferences = { theme: "dark" };

const settings = Object.assign({}, defaults, preferences);

console.log(settings);
// { theme: "dark", language: "en" }
```

The empty object is used as the target to avoid modifying `defaults`.

## 5. Combining Immutability with Array Methods

Objects and arrays are often updated together when processing application data.

```javascript
const students = [
  { id: 1, name: "Asha", active: true },
  { id: 2, name: "Dev", active: false }
];

const updatedStudents = students.map(student =>
  student.id === 2
    ? { ...student, active: true }
    : student
);

console.log(updatedStudents);
```

The code creates a new array and a new object for the student whose status changes. The original array and its objects are not directly modified.
