# React Day 10 Summary

- Extracts reusable logic into custom hooks.
- Applies the Rules of Hooks consistently.
- Implements fetching, local storage, debounce, and toggle hooks.
- Uses `useMemo` and `useCallback` for expensive or unstable values.
- Uses `React.memo` to prevent avoidable component renders.
- Measures component rendering with React Profiler.
- Adds global and local React Error Boundaries.
- Resets route-level error boundaries on navigation.
- Lazy-loads pages with `React.lazy` and `Suspense`.
- Includes a custom-hooks and performance refactoring project.
