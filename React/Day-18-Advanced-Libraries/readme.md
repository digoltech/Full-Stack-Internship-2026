# React Day 18 — Libraries for Everyday Frontend Work

Learn how focused libraries can improve form validation, remote-data handling, and interface feedback without replacing React fundamentals.

## Lessons

- [18.1 — Forms with React Hook Form and Zod](18.1-Forms-with-React-Hook-Form-and-Zod.md): schemas, field registration, accessible errors, submission, and server failures.
- [18.2 — Server State with TanStack Query](18.2-Server-State-with-TanStack-Query.md): provider setup, queries, query keys, mutations, caching, and request states.
- [18.3 — Motion and Icons](18.3-Motion-and-Icons.md): purposeful transitions, reduced motion, and accessible Lucide icons.
- [Day 18 Exercise](Exercise-Day-18.md): build a workshop registration admin feature using the tools together.

## Learning Outcomes

By the end of this day, you should be able to validate form data with a schema, distinguish local UI state from server state, handle loading/error/empty/success states, invalidate cached data after updates, and add motion or icons without hiding meaning from users.
