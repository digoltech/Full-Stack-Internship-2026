# Day 3.1 — JavaScript Objects and Nested Objects

## Learning Objectives

By the end of this session, students should be able to create objects, access and modify properties, work with nested objects, and use objects to represent real-world data.

## 1. What Is an Object?

An object stores related data as **key-value pairs**. It is useful when multiple properties belong to the same entity.

```javascript
const student = {
  name: "Rahil",
  age: 24,
  course: "MERN Stack",
  isActive: true
};

console.log(student.name);
console.log(student["course"]);
```

**Output:**
```text
Rahil
MERN Stack
```

Use dot notation when the property name is known. Use bracket notation when accessing a property dynamically.

```javascript
const key = "age";
console.log(student[key]); // 24
```

## 2. Adding, Updating, and Deleting Properties

```javascript
const product = {
  name: "Keyboard",
  price: 1200
};

// Add a property
product.category = "Electronics";

// Update a property
product.price = 1500;

// Delete a property
delete product.category;

console.log(product);
```

**Important:** `const` prevents reassignment of the object variable, but it does not prevent changes to the object's properties.

## 3. Methods Inside Objects

A function stored inside an object is commonly called a method.

```javascript
const user = {
  name: "Amit",
  greet: function () {
    console.log(`Hello, ${this.name}`);
  }
};

user.greet(); // Hello, Amit
```

Here, `this.name` refers to the `name` property of the object when the method is called as `user.greet()`.

## 4. Nested Objects

Objects can contain other objects, allowing us to represent structured information.

```javascript
const student = {
  name: "Neha",
  marks: {
    javascript: 85,
    react: 90
  },
  address: {
    city: "Anand",
    state: "Gujarat"
  }
};

console.log(student.marks.react); // 90
console.log(student.address.city); // Anand
```

### Optional Chaining

Use `?.` when a property may not exist. It prevents an error when accessing a property through `null` or `undefined`.

```javascript
console.log(student.contact?.email); // undefined
```

Without optional chaining, accessing `student.contact.email` would throw an error because `contact` does not exist.

## 5. Objects in Real Applications

API responses commonly contain objects and nested data.

```javascript
const order = {
  id: 101,
  customer: {
    name: "Priya",
    email: "priya@example.com"
  },
  items: [
    { name: "Mouse", price: 500 },
    { name: "Keyboard", price: 1200 }
  ]
};

console.log(order.customer.name);
console.log(order.items[0].name);
```

Students should become comfortable navigating this kind of data because it is common when working with frontend applications and backend APIs.

## Practice Tasks

### Task 1 — Object Basics
Create an employee object containing name, department, salary, and employee ID. Print every property using both dot and bracket notation.

### Task 2 — Modify an Object
Create a product object. Add a `stock` property, update its price, and delete one property.

### Task 3 — Nested Objects
Create a student object containing personal details, marks in three subjects, and address information. Print the student's city and highest-scoring subject's marks.

### Task 4 — Optional Chaining
Create a user object without a `social` property. Safely try to access `social.linkedin`.

### Review Questions
1. What is the difference between dot and bracket notation?
2. Can properties of a `const` object be modified?
3. What is a nested object?
4. What does optional chaining (`?.`) do?
5. What is a method in an object?
