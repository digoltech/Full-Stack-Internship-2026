# Day 5.1 — Modern JavaScript Features

## Learning Objectives

By the end of this session, students should be able to use template literals, optional chaining, nullish coalescing, logical operators, and modern syntax to write cleaner JavaScript.

## 1. Template Literals

Template literals use backticks and allow variables or expressions to be inserted with `${}`.

```javascript
const name = "Rahil";
const course = "MERN Stack";

console.log(`Hello ${name}, welcome to ${course}!`);
```

**Output:**
```text
Hello Rahil, welcome to MERN Stack!
```

You can also include calculations and multiline strings.

```javascript
const price = 500;
const quantity = 3;

console.log(`Total: ₹${price * quantity}`);
```

## 2. Optional Chaining (`?.`)

Optional chaining safely accesses properties that might not exist.

```javascript
const user = {
  name: "Asha",
  address: {
    city: "Anand"
  }
};

console.log(user.address?.city); // Anand
console.log(user.contact?.email); // undefined
```

It is especially useful when working with API responses where some fields may be missing.

Optional chaining does not make every expression safe. For example, it does not prevent errors when calling a property that exists but is not a function.

## 3. Nullish Coalescing (`??`)

The nullish coalescing operator provides a fallback only when the left-hand value is `null` or `undefined`.

```javascript
const username = null;

console.log(username ?? "Guest"); // Guest
```

Compare it with the logical OR operator:

```javascript
console.log(0 || 100);  // 100
console.log(0 ?? 100);  // 0

console.log("" || "Guest"); // Guest
console.log("" ?? "Guest"); // ""
```

Use `??` when zero, `false`, or an empty string might be valid values.

## 4. Logical Operators

Logical operators are useful for conditional logic.

```javascript
const isLoggedIn = true;
const isAdmin = false;

console.log(isLoggedIn && isAdmin); // false
console.log(isLoggedIn || isAdmin); // true
console.log(!isLoggedIn);           // false
```

### Short-Circuit Evaluation

JavaScript can return one of the operands instead of a Boolean.

```javascript
const user = null;

const name = user && user.name;
console.log(name); // null
```

For optional property access, `user?.name` is usually clearer.

## 5. Default Parameters

Default parameters provide a fallback when an argument is omitted or explicitly passed as `undefined`.

```javascript
function greet(name = "Guest") {
  return `Hello, ${name}`;
}

console.log(greet());          // Hello, Guest
console.log(greet("Asha"));    // Hello, Asha
console.log(greet(undefined)); // Hello, Guest
console.log(greet(null));      // Hello, null
```

A default parameter does not replace `null`.

## 6. Combining Modern Features

```javascript
function displayProfile(user = {}) {
  const name = user.name ?? "Unknown";
  const city = user.address?.city ?? "Not provided";

  return `${name} lives in ${city}`;
}

console.log(displayProfile({
  name: "Ravi",
  address: { city: "Surat" }
}));

console.log(displayProfile());
```

This style helps handle incomplete data without unnecessarily complicated conditional statements.

### Task 2 — Optional Chaining
