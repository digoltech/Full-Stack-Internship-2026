# Week 2 — Day 4.3: Responsive Design and CSS Modules

**Topics:** Mobile-first CSS, responsive layouts, CSS Modules, reusable styling

## 1. Responsive Layout

- Build layouts with CSS Grid and Flexbox.
- Start with mobile styles, then add wider media queries.
- Test at 320px, 768px, 1024px, and 1440px.
- Use `minmax()`, `clamp()`, `gap`, and relative units.
- Avoid fixed widths that can cause horizontal scrolling.

## 2. CSS Modules

```jsx
import styles from "./ProfileCard.module.css";

export function ProfileCard() {
  return <article className={styles.card}>Profile</article>;
}
```

- CSS Module class names are scoped to a component.
- Use a global stylesheet for reusable design tokens.
- Name modifiers for a component state, not an individual color.

## 3. Reusable Styling

- Store shared colors, spacing, borders, and shadows in CSS variables.
- Put layout composition in the parent and component styling in the child.
- Build a consistent button, card, input, and alert style.
- Keep repeated responsive rules close to the components that need them.

## 4. Accessibility

- Keep visible keyboard focus styles.
- Do not communicate status through color alone.
- Maintain sufficient color contrast.
- Use semantic landmarks and descriptive labels.
