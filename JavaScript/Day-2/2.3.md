# Day 2.3 — Array Iteration and Data Processing

## Learning Objectives

Learn to process arrays using `forEach()`, `map()`, `filter()`, and `find()`, and understand when to use each method.

## 1. `forEach()`

`forEach()` executes a callback for each element of an array. It is useful when you want to perform an action for every item.

```javascript
const names = ["Asha", "Ravi", "Neha"];

names.forEach(name => {
  console.log(name);
});
```

**Output:**
```text
Asha
Ravi
Neha
```

You can also access the current index:

```javascript
names.forEach((name, index) => {
  console.log(index, name);
});
```

**Remember:** `forEach()` returns `undefined`. It is not intended to create a transformed array.

## 2. `map()`

`map()` creates a new array by applying a callback to every element.

```javascript
const numbers = [1, 2, 3, 4];

const doubled = numbers.map(number => number * 2);

console.log(doubled); // [2, 4, 6, 8]
console.log(numbers); // [1, 2, 3, 4]
```

Use `map()` when you want to transform every item without changing the original array.

### Working with Objects

```javascript
const students = [
  { name: "Asha", marks: 70 },
  { name: "Ravi", marks: 85 }
];

const namesOnly = students.map(student => student.name);

console.log(namesOnly); // ["Asha", "Ravi"]
```

## 3. `filter()`

`filter()` creates a new array containing elements that satisfy a condition.

```javascript
const marks = [35, 65, 80, 42, 90];

const passed = marks.filter(mark => mark >= 50);

console.log(passed); // [65, 80, 90]
```

### Filtering Objects

```javascript
const students = [
  { name: "Asha", marks: 70 },
  { name: "Ravi", marks: 35 },
  { name: "Neha", marks: 90 }
];

const topStudents = students.filter(student => student.marks >= 80);

console.log(topStudents);
```

Use `filter()` when you want to select items rather than transform every item.

## 4. `find()`

`find()` returns the first element that satisfies a condition. If no element matches, it returns `undefined`.

```javascript
const students = [
  { id: 1, name: "Asha" },
  { id: 2, name: "Ravi" },
  { id: 3, name: "Neha" }
];

const student = students.find(student => student.id === 2);

console.log(student);
// { id: 2, name: "Ravi" }
```

Unlike `filter()`, `find()` returns a single matching element, not an array.

## 5. Choosing the Right Method

| Method | Purpose | Result |
|---|---|---|
| `forEach()` | Perform an action for each item | `undefined` |
| `map()` | Transform every item | New array |
| `filter()` | Select matching items | New array |
| `find()` | Find the first matching item | Element or `undefined` |

## 6. Combining Array Methods

These methods are often combined to process application data.

```javascript
const students = [
  { name: "Asha", marks: 45 },
  { name: "Ravi", marks: 80 },
  { name: "Neha", marks: 90 }
];

const successfulStudents = students
  .filter(student => student.marks >= 50)
  .map(student => student.name);

console.log(successfulStudents);
// ["Ravi", "Neha"]
```

First, `filter()` selects students who passed. Then, `map()` extracts their names.
