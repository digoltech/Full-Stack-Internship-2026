# JavaScript Day 1 Summary

- Introduces JavaScript execution in browsers and Node.js.
- Explains `var`, `let`, and `const` declarations.
- Covers global, function, and block scope.
- Demonstrates variable shadowing and common scope bugs.
- Shows how JavaScript hoists variables and functions.
- Introduces execution contexts and the temporal dead zone.
- Traces function calls with the call stack.
- Compares function declarations, expressions, and arrow functions.
- Uses parameters, return values, and basic validation.
- Includes a student result processor mini-project.
