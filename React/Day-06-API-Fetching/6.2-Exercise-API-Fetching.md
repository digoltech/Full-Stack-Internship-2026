### Section B — Expected Points

1. ```js
   if (!response.ok) throw new Error(`Status ${response.status}`);
   ```
   `fetch` only rejects on network failure; HTTP errors still resolve, so we must check manually.
2. Loading (spinner), error (message + retry), empty (no results message), success (list).
3. The user types `p` then `pho`. Request for `p` is slow and arrives after the request for `pho`, so the screen shows results for `p` while the box says `pho`. Fix with `AbortController` or by ignoring outdated results.
4. Reuse, easier changes of URL, simpler components, easier testing and error handling in one place.
5. `GET` reads data without a body; `POST` sends data in the body to create something. The header is required when the body is JSON, so the server knows how to parse it.

### Section E — Problems and Fix

Problems:

1. `async` effect callback.
2. Initial `products` is `undefined`, so `products.map` crashes when loading finishes or when an error occurs.
3. `loading` starts as `false`, so the first render crashes before the effect sets it to `true`.
4. `setLoading(false)` is never called.
5. No `response.ok` check and no `try/catch`.
6. Dependency array is `[]` but the effect uses `category`; data will not update when `category` changes.
7. Missing `key` in the list.
8. No error, empty states, or cleanup.
9. URL built by string concatenation; user-controlled values should be encoded.

Corrected version:

```jsx
import { useEffect, useState } from "react";

function Products({ category }) {
  const [products, setProducts] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState("");

  useEffect(() => {
    const controller = new AbortController();

    async function load() {
      try {
        setLoading(true);
        setError("");

        const res = await fetch(
          `https://dummyjson.com/products/category/${encodeURIComponent(category)}`,
          { signal: controller.signal }
        );
        if (!res.ok) throw new Error(`Status ${res.status}`);

        const data = await res.json();
        setProducts(data.products);
      } catch (err) {
        if (err.name !== "AbortError") setError(err.message);
      } finally {
        if (!controller.signal.aborted) setLoading(false);
      }
    }

    load();
    return () => controller.abort();
  }, [category]);

  if (loading) return <p>Loading...</p>;
  if (error) return <p role="alert">{error}</p>;
  if (products.length === 0) return <p>No products in this category.</p>;

  return (
    <ul>
      {products.map((p) => (
        <li key={p.id}>{p.title}</li>
      ))}
    </ul>
  );
}

export default Products;
```
