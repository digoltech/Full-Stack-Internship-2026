### Section B — Expected Points

1. Search → category filter → sort → paginate. Pagination must be last so that page numbers and the total number of pages are based on the **final filtered and sorted** list.
2. It is duplicate data that can become stale or out of sync. It can be calculated from `products`, `search`, and the other controls on every render.
3. The `draft` makes typing instant. The URL and the list update after the debounce delay, which avoids updating history and heavy work on every keystroke.
4. Advantages: instant interaction, simple code, no repeated requests. Disadvantages: large first download, high memory use, does not scale to thousands of items, data may be stale.
5. It creates as many columns as fit, each at least 220px wide, sharing any leftover width equally. The grid adapts to screen width without media queries.

Sample for Exercise 1:

```js
export function paginate(items, page, pageSize) {
  const totalItems = items.length;
  const totalPages = Math.max(1, Math.ceil(totalItems / pageSize));
  const safePage = Math.min(Math.max(Number(page) || 1, 1), totalPages);
  const start = (safePage - 1) * pageSize;

  return {
    items: items.slice(start, start + pageSize),
    page: safePage,
    totalPages,
    totalItems
  };
}
```

### Section E — Problems and Fix

Problems:

1. `products.sort` mutates the prop.
2. `sorted` is duplicate state, set in an effect (derived data does not need an effect).
3. Empty dependency array: sorting does not update when `products` changes. It also starts as `[]`, showing nothing in the first render.
4. Search is not lowercased (`search` could be uppercase), no `trim()`.
5. `totalPages` is not rounded up (`Math.ceil`), giving decimals.
6. `slice(page * 10, ...)` skips the first page; it should be `(page - 1) * 10`.
7. The page is not reset when `search` changes.
8. `Next` is not disabled on the last page; there is no Previous button.
9. Missing `key` in the list.
10. Search is not debounced (optional).

Corrected version:

```jsx
import { useState } from "react";

const PAGE_SIZE = 10;

function ProductList({ products }) {
  const [page, setPage] = useState(1);
  const [search, setSearch] = useState("");

  const normalized = search.trim().toLowerCase();

  const filtered = products.filter((p) =>
    p.title.toLowerCase().includes(normalized)
  );

  const sorted = [...filtered].sort((a, b) => a.price - b.price);

  const totalPages = Math.max(1, Math.ceil(sorted.length / PAGE_SIZE));
  const currentPage = Math.min(page, totalPages);
  const start = (currentPage - 1) * PAGE_SIZE;
  const visible = sorted.slice(start, start + PAGE_SIZE);

  function handleSearchChange(event) {
    setSearch(event.target.value);
    setPage(1);
  }

  return (
    <div>
      <input value={search} onChange={handleSearchChange} aria-label="Search" />

      {visible.map((p) => (
        <div key={p.id}>
          {p.title} - {p.price}
        </div>
      ))}

      <button onClick={() => setPage(currentPage - 1)} disabled={currentPage === 1}>
        Previous
      </button>
      <button onClick={() => setPage(currentPage + 1)} disabled={currentPage === totalPages}>
        Next
      </button>
      <p>Page {currentPage} of {totalPages}</p>
    </div>
  );
}

export default ProductList;
```
