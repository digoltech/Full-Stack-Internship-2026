# 15.2 — React Error Solving and Debugging

**Topics:** Components, state, effects, routing, API requests, accessibility

**Total Marks:** 50  
**Suggested Duration:** 35–45 minutes

## Instructions

Identify the issue, explain it briefly, and correct the code.

## Q1 — Direct State Mutation (5 Marks)

```jsx
function addItem(setItems) {
  setItems((previous) => {
    previous.push({ id: 1, name: "Keyboard" });
    return previous;
  });
}
```

## Q2 — Missing Effect Dependency (5 Marks)

```jsx
useEffect(() => {
  loadProducts(category);
}, []);
```

## Q3 — Array Index Used as a Key (5 Marks)

```jsx
items.map((item, index) => (
  <ItemCard key={index} item={item} />
))
```

## Q4 — Props Mutated Directly (5 Marks)

```jsx
function Profile({ user }) {
  user.name = "Updated Name";
  return <h2>{user.name}</h2>;
}
```

## Q5 — Conditional Hook (5 Marks)

```jsx
function Dashboard({ isAdmin }) {
  if (isAdmin) {
    const [count, setCount] = useState(0);
  }

  return <p>Dashboard</p>;
}
```

## Q6 — Incorrect Form Control (5 Marks)

```jsx
function NameForm() {
  const [name, setName] = useState("");
  return (
    <input value={name} onChange={() => setName("Asha")} />
  );
}
```

## Q7 — API 404 Treated as Success (5 Marks)

```jsx
async function loadProduct(id) {
  const response = await fetch(`/api/products/${id}`);
  return response.json();
}
```

## Q8 — Unhandled Fetch Rejection (5 Marks)

```jsx
useEffect(() => {
  fetch("/api/products")
    .then(response => response.json())
    .then(setProducts);
}, []);
```

## Q9 — Stale Search Response (5 Marks)

```jsx
useEffect(() => {
  fetch(`/api/search?q=${query}`)
    .then(response => response.json())
    .then(data => setResults(data.results));
}, [query]);
```

## Q10 — Button Without an Accessible Name (5 Marks)

```jsx
<button onClick={onClose}>
  <CloseIcon />
</button>
```

## Debugging Answer Notes

1. Return a new array with `[...previous, newItem]`.
2. Add `category` to the effect dependency array.
3. Use a stable unique key such as `item.id`.
4. Create and pass an updated copy instead of changing props.
5. Move `useState` above the condition and call it on every render.
6. Set state from `event.target.value`.
7. Check `response.ok` and throw or set an HTTP error state.
8. Add `.catch()` or wrap the request in `try/catch` and finally reset loading.
9. Use `AbortController` or ignore responses that no longer match the current query.
10. Add `aria-label="Close"` or visible accessible button text.
