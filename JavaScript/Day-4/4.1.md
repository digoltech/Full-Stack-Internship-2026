# Day 4.1 — ES Modules and Code Organization

## Learning Objectives

By the end of this session, students should understand how to split JavaScript code into multiple files, export reusable functions and variables, and import them into other files.

## 1. Why Do We Need Modules?

Writing an entire application in one JavaScript file makes it difficult to maintain and reuse code. Modules allow us to organize code into separate files based on responsibility.

For example:

```text
src/
├── math.js
├── user.js
└── main.js
```

Each file can provide specific functionality to the rest of the application.

## 2. Named Exports

A named export allows a file to expose specific functions, variables, or classes.

**math.js**

```javascript
export function add(a, b) {
  return a + b;
}

export function subtract(a, b) {
  return a - b;
}

export const PI = 3.14159;
```

**main.js**

```javascript
import { add, subtract, PI } from "./math.js";

console.log(add(10, 5));      // 15
console.log(subtract(10, 5)); // 5
console.log(PI);
```

The imported names must match the named exports unless you use aliases.

## 3. Default Exports

A module can also provide a default export.

**user.js**

```javascript
export default function greetUser(name) {
  return `Welcome, ${name}!`;
}
```

**main.js**

```javascript
import greetUser from "./user.js";

console.log(greetUser("Rahil"));
```

A module can have one default export and multiple named exports.

## 4. Import Aliases

You can rename named imports using `as`.

```javascript
import { add as calculateSum } from "./math.js";

console.log(calculateSum(4, 6)); // 10
```

This is useful when names conflict or when you want a more descriptive local name.

## 5. Organizing Application Code

Consider a simple application structure:

```text
src/
├── utils/
│   └── calculations.js
├── services/
│   └── userService.js
└── main.js
```

- `utils/` contains reusable helper functions.
- `services/` contains functions responsible for particular application operations.
- `main.js` connects the required modules.

Keeping each module focused makes an application easier to test, debug, and maintain.

## 6. Running ES Modules

In a browser, use a module script:

```html
<script type="module" src="./main.js"></script>
```

In Node.js, you can configure the project to use ES modules by adding `"type": "module"` to `package.json`, or by using the `.mjs` extension.

**Important:** When using Node.js ES modules, relative imports generally include the file extension, such as `./math.js`.

### Task 1 — Named Exports
Create `calculator.js` with functions for addition, subtraction, multiplication, and division. Export all four functions and import them into `main.js`.

### Task 2 — Default Export
Create a `student.js` module with a default-exported function that prints a student's name and course.

### Task 3 — Import Aliases

### Task 4 — Code Organization
