# Day 3.2 — Destructuring, Spread, and Rest Operators

## Learning Objectives

Understand how to extract values from arrays and objects, copy and combine data, and collect multiple values using the rest operator.

## 1. Array Destructuring

Destructuring allows us to extract array elements into variables.

```javascript
const colors = ["red", "green", "blue"];

const [first, second, third] = colors;

console.log(first);  // red
console.log(second); // green
console.log(third);  // blue
```

You can skip elements using commas.

```javascript
const numbers = [10, 20, 30];

const [first, , third] = numbers;

console.log(first, third); // 10 30
```

### Default Values

```javascript
const [name = "Unknown", age = 18] = ["Riya"];

console.log(name); // Riya
console.log(age);  // 18
```

## 2. Object Destructuring

Object destructuring extracts properties into variables with matching names.

```javascript
const student = {
  name: "Aarav",
  age: 21,
  course: "MERN"
};

const { name, age } = student;

console.log(name); // Aarav
console.log(age);  // 21
```

### Renaming Variables

```javascript
const { name: studentName } = student;

console.log(studentName); // Aarav
```

### Default Values

```javascript
const { city = "Anand" } = student;

console.log(city); // Anand
```

Destructuring is frequently used with function parameters and API responses.

```javascript
function displayStudent({ name, course }) {
  console.log(`${name} is learning ${course}`);
}

displayStudent(student);
```

## 3. Spread Operator (`...`)

The spread operator expands the elements of an iterable or the properties of an object into a new array or object.

### Copying an Array

```javascript
const original = [1, 2, 3];
const copied = [...original];

copied.push(4);

console.log(original); // [1, 2, 3]
console.log(copied);   // [1, 2, 3, 4]
```

### Combining Arrays

```javascript
const frontend = ["HTML", "CSS"];
const backend = ["Node.js", "MongoDB"];

const skills = [...frontend, ...backend];

console.log(skills);
```

### Copying and Updating Objects

```javascript
const user = {
  name: "Meera",
  city: "Anand"
};

const updatedUser = {
  ...user,
  city: "Ahmedabad"
};

console.log(updatedUser);
```

The original object remains unchanged because a new object was created.

**Note:** Spread creates a shallow copy. Nested objects are still shared references unless copied separately.

## 4. Rest Operator (`...`)

The rest operator collects remaining values into an array or object. Its meaning depends on where it is used.

### Rest with Arrays

```javascript
const [first, ...remaining] = [10, 20, 30, 40];

console.log(first);     // 10
console.log(remaining); // [20, 30, 40]
```

### Rest with Function Parameters

```javascript
function calculateTotal(...prices) {
  return prices.reduce((total, price) => total + price, 0);
}

console.log(calculateTotal(100, 200, 300)); // 600
```

### Rest with Objects

```javascript
const user = {
  name: "Jay",
  age: 22,
  password: "secret123"
};

const { password, ...publicProfile } = user;

console.log(publicProfile);
```

This creates a new object without the `password` property. Remember that excluding a property this way is not a replacement for proper security controls.
