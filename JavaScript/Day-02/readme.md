- Explains lexical scope and nested functions.
- Defines closures and how they preserve outer variables.
- Demonstrates closure factories and private state.
- Introduces callbacks and callback-based APIs.
- Covers higher-order functions and function composition.
- Uses `forEach()` to iterate over arrays.
- Uses `map()` to transform array values.
- Uses `filter()` and `find()` to select matching data.
- Combines array methods to process student or product data.
- Includes revision questions and a practice workbook.
