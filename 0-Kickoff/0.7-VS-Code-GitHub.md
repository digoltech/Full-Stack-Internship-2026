# 0.7 — Connect VS Code and GitHub

## Sign in to GitHub

1. Open VS Code.
2. Open the Accounts icon.
3. Choose **Sign in with GitHub**.
4. Approve VS Code in the browser.

## Clone a Repository

```powershell
git clone https://github.com/USERNAME/REPOSITORY.git
cd REPOSITORY
code .
```

You can also use **Source Control → Clone Repository**.

## Create a Branch

```powershell
git switch -c feature/day-1
```

Return to main:

```powershell
git switch main
```

## Commit from VS Code

1. Open the Source Control panel.
2. Review changed files.
3. Enter a meaningful commit message.
4. Select Commit.
5. Select Sync Changes or Push.

## Pull before Starting Work

```powershell
git pull origin main
```

Pulling first reduces merge conflicts and overwriting another student's or teammate's work.

## Never Commit

- `.env` secret values
- API keys
- Tokens
- Passwords
- Personal credentials
- `node_modules`
