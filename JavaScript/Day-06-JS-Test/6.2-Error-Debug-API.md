# 6.2 — JavaScript Error Solving and Debugging

**Topics:** Normal JavaScript bugs and asynchronous JavaScript bugs

**Total Marks:** 40  
**Suggested Duration:** 30 minutes

## Instructions

Identify the issue, explain it briefly, and correct the code.

## Normal JavaScript — Debug Questions

### Q1 — Closure State (5 Marks)

```javascript
function createCounter() {
  let count = 0;
  return count++;
}

const counter = createCounter();
console.log(counter());
```

### Q2 — Array Transformation (5 Marks)

```javascript
const prices = [100, 200, 300];
const pricesWithTax = prices.forEach(price => price * 1.18);

console.log(pricesWithTax);
```

### Q3 — Missing Nested Data (5 Marks)

```javascript
const student = { name: "Asha" };

console.log(student.address.city);
```

### Q4 — Immutable Update (5 Marks)

```javascript
const original = { name: "Ravi", role: "Student" };

original.role = "Mentor";
const updated = original;

console.log(original);
console.log(updated);
```

## Asynchronous JavaScript — Debug Questions

### Q5 — Missing Await (5 Marks)

```javascript
async function loadTasks() {
  const response = fetch("/api/tasks");
  const tasks = response.json();
  return tasks;
}
```

### Q6 — HTTP Error Treated as Success (5 Marks)

```javascript
async function loadUser(username) {
  const response = await fetch(`/api/users/${username}`);
  const user = await response.json();
  return user;
}
```

### Q7 — Unhandled Rejected Request (5 Marks)

```javascript
async function loadProducts() {
  const response = await fetch("/api/products");
  const data = await response.json();
  return data;
}

loadProducts();
```

### Q8 — Stale Search Results (5 Marks)

```javascript
async function search(query) {
  const response = await fetch(`/api/search?q=${query}`);
  const data = await response.json();
  renderResults(data.results);
}

search("phone");
search("laptop");
```

## Debugging Answer Notes

1. Return a function that increments the retained `count` variable.
2. Use `map()` instead of `forEach()` when creating a transformed array.
3. Use `student.address?.city`, or the optional chaining operator twice.
4. Create a new object with spread syntax and leave the original unchanged.
5. Await both `fetch()` and `response.json()`.
6. Check `response.ok` and throw or return a clear HTTP error.
7. Wrap the request and parsing in `try/catch`, or attach error handling.
8. Abort the previous request or ignore responses that no longer match the current query.
