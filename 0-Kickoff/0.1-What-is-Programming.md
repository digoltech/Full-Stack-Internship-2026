# 0.1 — What Is Programming?

Programming is the process of giving a computer clear instructions to solve a problem.

A useful program usually follows four steps:

1. **Input:** receive data, such as text, a click, or an API response.
2. **Processing:** apply rules and calculations.
3. **Output:** display, save, or send a result.
4. **Storage:** remember information when needed.

```text
Input → Process → Decision → Output
  5      + 3        true       8
```

## Variables

A variable is a named place in memory that stores a value.

```javascript
const name = "Asha";
let score = 10;
score = score + 5;
```

## Data Types

- **Number:** `10`, `3.5`
- **String:** `"Hello"`
- **Boolean:** `true`, `false`
- **Array:** `["HTML", "CSS", "JavaScript"]`
- **Object:** `{ name: "Asha", role: "Intern" }`
- **Null:** an intentional empty value
- **Undefined:** a value that has not been assigned

## Control Flow

```javascript
const marks = 72;

if (marks >= 50) {
  console.log("Passed");
} else {
  console.log("Needs practice");
}
```

Loops repeat work. Functions package reusable work.

```javascript
function welcome(name) {
  return `Welcome, ${name}!`;
}
```

A programmer does not memorize every command. The important skills are problem decomposition, debugging, reading errors, and testing.
