# Exercise Day 3 — Conditional and List Rendering

Build a course and student dashboard that demonstrates conditional rendering and list rendering.

## Requirements

1. Store a list of at least six student or course objects in state or local data.
2. Render the list using `map()` and unique `key` values.
3. Add a filter for All, Active, and Completed items.
4. Use a ternary expression for at least one conditional UI state.
5. Use the logical AND operator for at least one conditional UI element.
6. Display a different empty-state message when no items match.
7. Show a loading message for a controlled loading state.
8. Show an error message for a controlled error state.
9. Create at least three reusable components.
10. Do not use array `index` values as React keys.

## Submission

- Create or update a Vite React project.
- Keep each component in a readable, meaningful file.
- Test All, Active, Completed, and empty-filter states.
- Fix all React key and conditional-rendering warnings.
