# Exercise Day 13 — Automated React Tests

Add automated tests to an existing React feature.

## Requirements

- [ ] Install Vitest and Testing Library.
- [ ] Add a test script to `package.json`.
- [ ] Test at least three user interactions.
- [ ] Test at least one validation state.
- [ ] Test at least five utility or reducer scenarios.
- [ ] Use role and label queries instead of CSS selectors.
- [ ] Test an empty or no-results state.
- [ ] Keep tests independent of one another.
- [ ] Use a focused regression test for every intentionally fixed bug.
- [ ] Run `npm test` successfully.

## Submission

Report the test commands, test count, and one bug found only through testing.
