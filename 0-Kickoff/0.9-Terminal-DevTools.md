# 0.9 — Terminal and Browser DevTools

## Terminal Basics

```powershell
pwd
cd folder-name
cd ..
ls
mkdir project-name
code .
```

Use `Tab` for path completion and the up-arrow key for previous commands.

## Browser DevTools

Open DevTools with `F12` or `Ctrl+Shift+I`.

Important panels:

- **Elements:** inspect HTML and computed CSS.
- **Console:** run JavaScript and read errors.
- **Sources:** step through JavaScript.
- **Network:** inspect API requests and responses.
- **Application:** inspect localStorage and sessionStorage.
- **Lighthouse:** audit accessibility and performance.

## Common Debugging Process

1. Reproduce the problem.
2. Read the first error.
3. Open the relevant file or network request.
4. Test one hypothesis.
5. Fix only the confirmed cause.
6. Repeat the original steps.
7. Add a test or checklist after the fix.

## Read an API Failure

Check:

- Request URL
- HTTP method
- Request payload
- Response status
- Response body
- Browser console
- CORS or network message
