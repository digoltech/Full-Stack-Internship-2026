# Week 4 — Day 13.2: Testing Exercises

## Exercise 1 — Counter Test

Write tests for:

1. Initial value.
2. Increment.
3. Decrement.
4. Reset.
5. A minimum value that cannot be exceeded.

## Exercise 2 — Form Test

Write tests for:

1. Required validation.
2. Invalid email handling.
3. Successful submission.
4. The submitted value or success message.

## Exercise 3 — Utility Test

Test a pure `filterAndSortItems()` function for:

1. Empty input.
2. Search matching.
3. Sorting.
4. Combined search and category filters.
5. No mutation of the original array.

## Exercise 4 — Debugging

Fix and test an app containing one mutation bug, one stale dependency, and one missing accessible label.
