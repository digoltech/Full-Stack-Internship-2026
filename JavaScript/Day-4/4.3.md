# Day 4.3 — Promises and Async/Await

## Learning Objectives

Understand asynchronous JavaScript, promises, promise states, `.then()`, `.catch()`, `async`, `await`, and basic API requests using `fetch()`.

## 1. Synchronous vs Asynchronous JavaScript

Synchronous operations execute in sequence. Asynchronous operations allow JavaScript to continue with other work while waiting for an operation to complete.

```javascript
console.log("Start");

setTimeout(() => {
  console.log("Delayed task");
}, 1000);

console.log("End");
```

**Output:**

```text
Start
End
Delayed task
```

The timer callback runs later, after the synchronous statements have executed.

## 2. What Is a Promise?

A Promise represents the eventual result of an asynchronous operation.

A promise has three states:

- **Pending:** The operation has not settled.
- **Fulfilled:** The operation completed successfully.
- **Rejected:** The operation failed.

```javascript
const promise = new Promise((resolve, reject) => {
  const success = true;

  if (success) {
    resolve("Operation successful");
  } else {
    reject(new Error("Operation failed"));
  }
});

promise
  .then(result => console.log(result))
  .catch(error => console.error(error.message));
```

`resolve()` fulfills the promise, while `reject()` rejects it.

## 3. Promise Chaining

The `.then()` method handles a fulfilled promise and returns a new promise, allowing operations to be chained.

```javascript
Promise.resolve(5)
  .then(number => number * 2)
  .then(number => number + 10)
  .then(result => console.log(result))
  .catch(error => console.error(error));
```

**Output:**

```text
20
```

Errors in the chain can be handled with `.catch()`.

## 4. What Is `async`?

An `async` function always returns a Promise. If it returns a regular value, that value becomes the fulfillment value of the returned promise.

```javascript
async function getMessage() {
  return "Hello from async";
}

getMessage().then(message => console.log(message));
```

**Output:**

```text
Hello from async
```

Even though the function returns a string in its body, callers receive a Promise.

## 5. What Is `await`?

`await` pauses the execution of the surrounding async function until the awaited promise settles. It does not block the entire JavaScript thread.

```javascript
function getNumber() {
  return new Promise(resolve => {
    setTimeout(() => resolve(10), 1000);
  });
}

async function displayNumber() {
  console.log("Waiting...");

  const number = await getNumber();

  console.log(number);
}

displayNumber();
```

The async function waits for the promise before printing the number.

## 6. Error Handling with Async/Await

Use `try...catch` to handle errors from awaited promises.

```javascript
function getData() {
  return Promise.reject(new Error("Request failed"));
}

async function loadData() {
  try {
    const result = await getData();
    console.log(result);
  } catch (error) {
    console.error("Error:", error.message);
  }
}

loadData();
```

This style often makes asynchronous code easier to read.

## 7. Making API Requests with `fetch()`

The `fetch()` API sends HTTP requests and returns a Promise.

```javascript
async function loadUsers() {
  try {
    const response = await fetch(
      "https://jsonplaceholder.typicode.com/users"
    );

    if (!response.ok) {
      throw new Error(`HTTP error: ${response.status}`);
    }

    const users = await response.json();

    console.log(users);
  } catch (error) {
    console.error("Unable to load users:", error.message);
  }
}

loadUsers();
```

Important points:

- `fetch()` returns a Promise.
- `response.json()` also returns a Promise.
- HTTP errors such as 404 do not automatically reject the `fetch()` promise, so check `response.ok`.
- Network failures and parsing errors can be handled through `try...catch`.

## 8. Running Independent Requests Together

When independent operations do not depend on each other's results, `Promise.all()` can run them concurrently.

```javascript
async function loadData() {
  try {
    const [usersResponse, postsResponse] = await Promise.all([
      fetch("https://jsonplaceholder.typicode.com/users"),
      fetch("https://jsonplaceholder.typicode.com/posts")
    ]);

    if (!usersResponse.ok || !postsResponse.ok) {
      throw new Error("One or more requests failed");
    }

    const [users, posts] = await Promise.all([
      usersResponse.json(),
      postsResponse.json()
    ]);

    console.log(users.length);
    console.log(posts.length);
  } catch (error) {
    console.error(error.message);
  }
}

loadData();
```

`Promise.all()` rejects if any input promise rejects. For independent requests where every outcome matters, students can later explore `Promise.allSettled()`.
