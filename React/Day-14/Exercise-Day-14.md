# Exercise Day 14 — Architecture and Styling Review

Improve one React project using reusable styling and a clear folder architecture.

## Requirements

- [ ] Organize code into app, components, features, hooks, services, and utilities.
- [ ] Add reusable Button, Card, Loader, and ErrorMessage components.
- [ ] Use CSS Modules or Tailwind consistently.
- [ ] Create shared design tokens or theme variables.
- [ ] Add one responsive layout change for mobile and desktop.
- [ ] Keep components free of direct API implementation details.
- [ ] Remove duplicated utility or layout classes.
- [ ] Add or update the professional README.
- [ ] Use at least three meaningful Git commits.
- [ ] Use one feature branch and describe the completed change in a pull request.

## Viva Questions

1. How does your folder structure help a team find code?
2. Which state should live in a feature folder?
3. What is the advantage of utility-first CSS?
4. How would you reuse a visual pattern across pages?
5. What information should an architecture diagram communicate?
