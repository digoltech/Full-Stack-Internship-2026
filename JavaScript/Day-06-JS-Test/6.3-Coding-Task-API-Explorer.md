# 6.3 — JavaScript Coding Tasks

**Total Marks:** 50  
**Suggested Duration:** 60–90 minutes

## Coding Task 1 — Normal JavaScript Student Manager (25 Marks)

Create a plain JavaScript program that manages a list of student records.

### Requirements

1. Create at least five student objects containing `id`, `name`, `marks`, and `city`.
2. Use `map()` to create an array of student names.
3. Use `filter()` to select students with marks of 50 or more.
4. Use `find()` to locate a student by ID.
5. Use `reduce()` to calculate the average or total marks.
6. Use array and object destructuring.
7. Use optional chaining or a default value for missing city data.
8. Create one updated student object without modifying the original object.
9. Sort a copy of the student array by marks, without mutating the original.
10. Print the list and summary in a readable console format.

### Submission

- Submit one JavaScript file.
- Separate transformations into named functions.
- Do not use direct mutation of the original student array or objects.
- Include a short comment for one closure or higher-order function used.

## Coding Task 2 — Asynchronous JavaScript API Explorer (25 Marks)

Create a browser-based API explorer using `fetch()`, `async/await`, and a public API.

### Requirements

1. Create a search input and submit button.
2. Fetch data only after a valid search is submitted.
3. Show loading text while the request is running.
4. Check `response.ok` before parsing the response.
5. Parse the JSON response with `await response.json()`.
6. Render at least five matching items.
7. Show a clear no-results message.
8. Show a clear error message for HTTP, parsing, and network failures.
9. Prevent stale responses with `AbortController` or a request identifier.
10. Use `try/catch/finally` and organize request logic into functions.

### Suggested Structure

```text
day-6-api-explorer/
├── index.html
├── styles.css
└── script.js
```

### Submission

- Submit the HTML, CSS, and JavaScript files.
- The app must run in a browser.
- The console must contain no uncaught errors.
- The README or submission note must explain loading, empty, and error states.
