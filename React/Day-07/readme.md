# React Day 7 Summary

- Introduces client-side routing with React Router.
- Creates nested layouts and reusable navigation components.
- Defines static and dynamic routes.
- Uses `Link` and `NavLink` instead of full-page navigation.
- Reads route parameters with `useParams()`.
- Reads and updates the query string with `useSearchParams()`.
- Uses wildcard routes for not-found pages.
- Builds a layout with nested `<Outlet />` components.
- Explains navigation, route guards, and deep links.
- Includes a multi-page catalogue project.
