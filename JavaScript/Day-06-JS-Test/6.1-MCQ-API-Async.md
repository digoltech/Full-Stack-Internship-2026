# 6.1 — JavaScript MCQ Test

**Topics:** Synchronous JavaScript and asynchronous JavaScript

**Total Marks:** 20  
**Suggested Duration:** 20 minutes

*Choose one answer for each question. Each question carries 1 mark.*

## Section A — Normal JavaScript (10 Marks)

1. Which keyword declares a block-scoped variable that can be reassigned?
   - A. `var`
   - B. `let`
   - C. `const`
   - D. `static`

2. What does this code print?
   ```javascript
   function outer() {
     let count = 2;
     return () => ++count;
   }
   const counter = outer();
   console.log(counter(), counter());
   ```
   - A. `2 2`
   - B. `3 4`
   - C. `2 3`
   - D. `1 2`

3. Which array method creates a new array containing every transformed element?
   - A. `forEach()`
   - B. `map()`
   - C. `find()`
   - D. `some()`

4. What is the result of `[2, 4, 6].filter(number => number > 3)`?
   - A. `[2, 4, 6]`
   - B. `[4, 6]`
   - C. `[6]`
   - D. `true`

5. Which syntax correctly renames `name` during object destructuring?
   - A. `{ name = studentName }`
   - B. `{ name: studentName }`
   - C. `{ studentName: name }`
   - D. `{ name -> studentName }`

6. What does `{ ...student, marks: 90 }` do?
   - A. Mutates `student`
   - B. Creates a new object with updated `marks`
   - C. Deletes `marks`
   - D. Converts `student` to JSON

7. Which operator provides a fallback only for `null` or `undefined`?
   - A. `||`
   - B. `??`
   - C. `&&`
   - D. `?.`

8. What does `JSON.parse('{"name":"Asha"}')` return?
   - A. A JSON string
   - B. An object
   - C. `undefined`
   - D. An array

9. What does `reduce()` commonly return?
   - A. A single accumulated value
   - B. A copied array only
   - C. The first matching element
   - D. Always a Boolean

10. Which method stores a JSON string in `localStorage`?
    - A. `localStorage.save("tasks", tasks)`
    - B. `localStorage.setItem("tasks", JSON.stringify(tasks))`
    - C. `localStorage.add("tasks", tasks)`
    - D. `localStorage.JSON(tasks)`

## Section B — Asynchronous JavaScript (10 Marks)

11. What does `fetch()` return?
    - A. A plain object
    - B. A Promise
    - C. Parsed JSON
    - D. A string

12. What does `response.ok` indicate?
    - A. The network cable is connected
    - B. The HTTP status is in the 200–299 range
    - C. The response JSON is valid
    - D. The browser is online

13. Which method converts a successful response body to a JavaScript value?
    - A. `response.parse()`
    - B. `response.textToJson()`
    - C. `response.json()`
    - D. `response.object()`

14. Which statement is true about an `async` function?
    - A. It always returns a Promise
    - B. It never uses `await`
    - C. It executes only in Node.js
    - D. It cannot contain `try/catch`

15. Where can `await` be used directly?
    - A. Inside any callback
    - B. Inside an `async` function or supported top-level module
    - C. Outside every function only
    - D. Inside a regular `for` loop without an async function

16. Which block handles an error inside an asynchronous function?
    - A. `catch` after a Promise or `try/catch`
    - B. `else`
    - C. `switch`
    - D. `finally` only

17. What normally runs first after the current synchronous code finishes?
    ```javascript
    console.log("A");
    Promise.resolve().then(() => console.log("B"));
    console.log("C");
    ```
    - A. A, B, C
    - B. A, C, B
    - C. B, A, C
    - D. C, B, A

18. Which Promise combinator rejects as soon as one input Promise rejects?
    - A. `Promise.all()`
    - B. `Promise.resolve()`
    - C. `Promise.any()`
    - D. `Promise.allSettled()` ignores rejection

19. What does `AbortController` commonly help prevent?
    - A. State mutation
    - B. Stale or obsolete HTTP responses
    - C. Array sorting
    - D. JSON parsing

20. What happens when `fetch()` receives an HTTP 404 response?
    - A. `fetch()` always throws automatically
    - B. The Promise resolves, and code must check `response.ok`
    - C. JavaScript returns `undefined`
    - D. The browser restarts
