# Day 2.3 — Array Iteration and Data Processing

## Learning Objectives

Learn how to use `forEach()`, `map()`, `filter()`, and `find()` to work with arrays in JavaScript.

## 1. `forEach()`

`forEach()` runs a function for every item in an array. Use it when you want to print or perform an action on each item.

**Example 1: Print names**

```javascript
const names = ["Asha", "Ravi", "Neha"];

names.forEach(name => {
  console.log(name);
});
```

**Output:**
```text
Asha
Ravi
Neha
```

**Example 2: Print numbers with their index**

```javascript
const numbers = [10, 20, 30];

numbers.forEach((number, index) => {
  console.log(index, number);
});
```

**Output:**
```text
0 10
1 20
2 30
```

**Real-life example:** Printing the names of all students attending an internship.

**Remember:** `forEach()` does not return a new array.

## 2. `map()`

`map()` creates a new array by changing each item according to your instructions.

**Example 1: Double the numbers**

```javascript
const numbers = [1, 2, 3, 4];

const result = numbers.map(number => number * 2);

console.log(result);
```

**Output:**
```javascript
[2, 4, 6, 8]
```

**Example 2: Extract student names**

```javascript
const students = [
  { name: "Asha", marks: 70 },
  { name: "Ravi", marks: 85 },
  { name: "Neha", marks: 90 }
];

const names = students.map(student => student.name);

console.log(names);
```

**Output:**
```javascript
["Asha", "Ravi", "Neha"]
```

**Real-life example:** Converting a list of products into a list containing only their names for display on a website.

**Remember:** `map()` returns a new array and does not change the original array.

## 3. `filter()`

`filter()` creates a new array containing only the items that satisfy a condition.

**Example 1: Get numbers greater than 10**

```javascript
const numbers = [5, 12, 8, 20, 15];

const result = numbers.filter(number => number > 10);

console.log(result);
```

**Output:**
```javascript
[12, 20, 15]
```

**Example 2: Find students who passed**

```javascript
const marks = [35, 75, 45, 90, 60];

const passed = marks.filter(mark => mark >= 50);

console.log(passed);
```

**Output:**
```javascript
[75, 90, 60]
```

**Example 3: Filter products by price**

```javascript
const products = [
  { name: "Mouse", price: 500 },
  { name: "Keyboard", price: 1500 },
  { name: "Headphones", price: 800 }
];

const affordable = products.filter(product => product.price < 1000);

console.log(affordable);
```

**Output:** Mouse and Headphones.

**Real-life example:** Showing only available products or affordable products in an e-commerce store.

## 4. `find()`

`find()` returns the **first item** that matches a condition. If no item matches, it returns `undefined`.

**Example 1: Find a number**

```javascript
const numbers = [10, 20, 30, 40];

const result = numbers.find(number => number > 20);

console.log(result);
```

**Output:**
```javascript
30
```

It returns `30` because it is the first number greater than 20.

**Example 2: Find a student by ID**

```javascript
const students = [
  { id: 1, name: "Asha" },
  { id: 2, name: "Ravi" },
  { id: 3, name: "Neha" }
];

const student = students.find(student => student.id === 2);

console.log(student);
```

**Output:**
```javascript
{ id: 2, name: "Ravi" }
```

**Real-life example:** Finding a particular user by ID or searching for a product by its ID.

**Remember:** `find()` returns one item, while `filter()` can return multiple items.

## 5. Quick Comparison

| Method | Purpose | Returns |
|---|---|---|
| `forEach()` | Perform an action on every item | `undefined` |
| `map()` | Transform every item | New array |
| `filter()` | Select matching items | New array |
| `find()` | Find the first matching item | Item or `undefined` |

## 6. Combining Array Methods

You can combine methods to process data in fewer steps.

**Example: Get names of students who scored 50 or more**

```javascript
const students = [
  { name: "Asha", marks: 45 },
  { name: "Ravi", marks: 80 },
  { name: "Neha", marks: 90 }
];

const result = students
  .filter(student => student.marks >= 50)
  .map(student => student.name);

console.log(result);
```

**Output:**
```javascript
["Ravi", "Neha"]
```

**How it works:**
1. `filter()` selects students with marks of 50 or more.
2. `map()` extracts their names.
