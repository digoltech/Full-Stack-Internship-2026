# React Day 5 Summary

- Lifts shared state to the closest common component.
- Uses callback props to send events up to parent components.
- Updates arrays and objects immutably.
- Stores application data in `localStorage`.
- Uses lazy state initialization for persisted values.
- Handles corrupted storage with `try/catch`.
- Uses `useRef` for focus and DOM interactions.
- Derives counts and filtered lists instead of duplicating state.
- Builds reusable task manager components.
- Includes a persistent Task Manager Pro exercise.
